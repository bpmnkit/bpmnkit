# bpmnkit-connectors

Connector element templates for BPMN Kit: generate them from OpenAPI/Swagger specs and bind them onto BPMN elements. Rust twin of `@bpmnkit/connector-gen`.

## Install

```sh
cargo add bpmnkit-connectors
```

## Usage

Driven by `bpmnkit connector gen` and `bpmnkit connector bind`.

Part of [BPMN Kit](https://bpmnkit.com). MIT OR Apache-2.0.
