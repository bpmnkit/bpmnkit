# bpmnkit-profiles

Profile store paths for the BPMN Kit CLI, with the copy-never-move migration from the legacy `casen` directory. Rust twin of the `@bpmnkit/profiles` config lookup.

## Install

```sh
cargo add bpmnkit-profiles
```

## Usage

Used by the `bpmnkit` CLI and the plugin environment contract.

Part of [BPMN Kit](https://bpmnkit.com). MIT OR Apache-2.0.
