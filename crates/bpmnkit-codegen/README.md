# bpmnkit-codegen

Deterministic job worker code generation: Rust, Java (Maven or Gradle, plain or Spring) and template emitters, a lock file, and `--check` drift detection. Same input, same bytes.

## Install

```sh
cargo add bpmnkit-codegen
```

## Usage

Driven by `bpmnkit worker gen <bpmn> --lang java|rust`.

Part of [BPMN Kit](https://bpmnkit.com). MIT OR Apache-2.0.
