# bpmnkit-connector-runtime

Local runner for Camunda 8 REST connector jobs (`io.camunda:http-json:1`): secrets, FEEL result/error expressions and auth, on top of `bpmnkit-worker`.

## Install

```sh
cargo add bpmnkit-connector-runtime
```

## Usage

Driven by `bpmnkit connector run` and `bpmnkit connector test`.

Part of [BPMN Kit](https://bpmnkit.com). MIT OR Apache-2.0.
