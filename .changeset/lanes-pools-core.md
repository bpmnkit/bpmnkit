Lanes, pools and message flows can be written. `ProcessBuilder.lane()` and `.participant()`, `DiagramBuilder.withAutoLayout()`; the compact format's `lanes`, `executable`, `participants` and `messageFlows` keys (`CompactLane`, `CompactParticipant`, `CompactMessageFlow`), which `reconcileCompact` checks; `lane`, `pool` and `msg` lines in process text, written by `writeProcessText` and read by `parseProcessText` and `parseProcessDelta` (with `- msg`). Auto-layout insets nested lanes and draws lane bands for a laned process without a pool. New helpers: `allLanes`, `leafLanes`, `laneOf`, `assignLane`, `laneForNewNode`, `laneProblems`, `collaborationProblems`, `messageEndProblem`, `primaryProcess`, `pinPrimaryProcess`, `nameFromId`, `writableMessageLabel`, `POOL_LINE`, `MESSAGE_LINE`. `BpmnDefinitions.primaryProcessId` is written as `bpmnkit:primaryProcess` on `<definitions>` only when the file alone would lead `primaryProcess` to another process. Continuing a laned document puts a new node in its predecessor's lane; `DiagramBuilder` keeps a child process's pool and refuses a collaboration in which a process with content has no participant.
