# Configure MCP Client connectors — HTTP proxy support

In Self-Managed environments, the MCP Client connector supports HTTP proxy configuration, including [plain proxy variables](https://docs.camunda.io/docs/next/self-managed/components/connectors/http-proxy-configuration#plain-proxy-variables). See the [AI Agent connector proxy configuration](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/agentic-ai-aiagent-customization#http-proxy-configuration) for details, including how to disable proxy support.
