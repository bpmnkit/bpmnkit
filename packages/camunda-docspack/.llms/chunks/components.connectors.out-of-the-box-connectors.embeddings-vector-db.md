# Vector Database connector

Embed, store, and retrieve LLM embeddings and store them in vector databases.

The **Vector Database connector** allows embedding, storing, and retrieving Large Language Model (LLM) embeddings.

This enables building AI-based solutions such as context document search, long-term LLM memory, and agentic AI interaction. For an example, see how to [add long-term memory to your AI agents](https://docs.camunda.io/docs/next/components/agentic-orchestration/rag-ai-agents).

**Note**
The **Vector Database connector** uses the [LangChain4j](https://docs.langchain4j.dev/) library. Data models and possible implementations are limited
to the latest stable released LangChain4j library.
