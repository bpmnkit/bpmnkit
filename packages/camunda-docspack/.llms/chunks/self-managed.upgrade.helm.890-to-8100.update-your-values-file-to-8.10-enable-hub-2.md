# Upgrade Camunda 8.9 to 8.10 using Helm — Update your values file to 8.10 — Enable Hub (2)

#### Move or remove `console` keys

The chart reads only `console.enabled`. It ignores every other `console.*` key. It emits a single deprecation warning when you set any of them. Move the settings that you still need to Hub. Then remove the `console` block:

| 8.9 key                                                                                                                                                                                                                                                                                                                                             | 8.10 key or action                                                                                                                                                                                                                                                                                                 |
| :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `console.resources`                                                                                                                                                                                                                                                                                                                                 | `camundaHub.restapi.resources`. See [Review Hub REST API resources](#review-hub-rest-api-resources).                                                                                                                                                                                                               |
| `console.env`, `console.envFrom`                                                                                                                                                                                                                                                                                                                    | `camundaHub.restapi.env`, `camundaHub.restapi.envFrom`. Don't move `CAMUNDA_CONSOLE_*` variables or `camunda.console` properties. Hub fails on startup if you set them. See [Console configuration](https://docs.camunda.io/docs/next/self-managed/upgrade/components/890-to-8100#console-configuration).                                        |
| `console.replicas`, `console.nodeSelector`, `console.tolerations`, `console.affinity`, `console.podLabels`, `console.podAnnotations`, `console.extraVolumes`, `console.extraVolumeMounts`, `console.initContainers`, `console.sidecars`, `console.podSecurityContext`, `console.containerSecurityContext`, `console.dnsPolicy`, `console.dnsConfig` | Use the same keys under `camundaHub.restapi`. Lists replace the `webModeler.restapi` lists. See [Merge `webModeler` and `camundaHub` values](#merge-webmodeler-and-camundahub-values).                                                                                                                             |
| `console.serviceAccount.*`                                                                                                                                                                                                                                                                                                                          | `camundaHub.serviceAccount.*`. The Hub REST API and WebSockets pods share this service account.                                                                                                                                                                                                                    |
| `console.contextPath`                                                                                                                                                                                                                                                                                                                               | No equivalent. Hub serves Console's pages on `camundaHub.contextPath`.                                                                                                                                                                                                                                             |
| `console.configuration`, `console.extraConfiguration`, `console.overrideConfiguration`                                                                                                                                                                                                                                                              | Cluster configuration moves to `camundaHub.restapi.clusters`. If you set this key, your value replaces the cluster list the chart generates for the release. As a result, list the release's own clusters too. See [cluster configuration](https://docs.camunda.io/docs/next/self-managed/upgrade/components/890-to-8100#cluster-configuration). |
| `console.image.registry`, `console.image.pullSecrets`                                                                                                                                                                                                                                                                                               | `camundaHub.image.registry`, `camundaHub.image.pullSecrets`.                                                                                                                                                                                                                                                       |
| `console.image.repository`, `console.image.tag`, `console.image.digest`                                                                                                                                                                                                                                                                             | No equivalent. Remove these keys. To pin Hub images, see [Update image references](#update-image-references).                                                                                                                                                                                                      |
| `console.tls.*`                                                                                                                                                                                                                                                                                                                                     | If Console needed these keys to trust a private CA, add that CA to the PEM bundle in `global.tls.caBundle.secret`. Otherwise, remove them.                                                                                                                                                                         |
| `console.keycloak.realm`                                                                                                                                                                                                                                                                                                                            | No equivalent. Remove this key.                                                                                                                                                                                                                                                                                    |

`global.identity.auth.console.*` has no effect in 8.10, and the chart emits a deprecation warning when you set it. For a Console-only release, set `global.identity.auth.camundaHub.redirectUrl` to Hub's public URL. This key replaces `global.identity.auth.console.redirectUrl`. The other keys have no direct replacement, so remove them.

Management Identity doesn't remove the existing `console` client from Keycloak. See [Management Identity roles and permissions](https://docs.camunda.io/docs/next/self-managed/upgrade/components/890-to-8100#management-identity-roles-and-permissions).

#### Update references to Console

The chart no longer renders the Console Deployment, Service, ServiceMonitor, and HTTPRoute, or the `/console` path on the shared Ingress. Helm removes them during the upgrade. Update bookmarks, external Ingress or Gateway routes, and monitoring that target Console to use Hub instead. If the chart renders your Ingress or Gateway API routes, set `camundaHub.contextPath`. Without it, the shared Ingress has no Hub path, and the Kubernetes API server rejects the Hub HTTPRoute.
