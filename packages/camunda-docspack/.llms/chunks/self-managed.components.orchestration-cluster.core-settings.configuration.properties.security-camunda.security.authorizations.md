# Property reference — Security — `camunda.security.authorizations`

| Property                                  | Description                                                       | Default value | Overridable per Physical Tenant |
| ----------------------------------------- | ----------------------------------------------------------------- | ------------- | :------------------------------ |
| `camunda.security.authorizations.enabled` | Enables authorization checks for Orchestration Cluster resources. | `true`        | Yes                             |
