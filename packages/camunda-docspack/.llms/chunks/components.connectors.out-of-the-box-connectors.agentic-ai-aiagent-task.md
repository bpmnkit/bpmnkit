# AI Agent Task connector

AI agent connector implementation based on service tasks.

Implement an AI agent using an AI Agent connector applied to a service task, paired with an optional ad-hoc sub-process to provide tools usable by the AI.

**Info**

- For more information and usage examples, see [AI Agent Task](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/agentic-ai-aiagent#ai-agent-task).
- The [example integration](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/agentic-ai-aiagent-task-example) page outlines how to model an agentic AI process using the AI Agent Task implementation.
