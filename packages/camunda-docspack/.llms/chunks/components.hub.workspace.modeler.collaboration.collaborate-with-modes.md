# Collaborate with modes

Dedicated modes are ways for business and IT professionals to collaborate effectively.

Use **Design**, **Implement**, and **Test** modes to collaborate effectively with members with different technical backgrounds.


## About

[**Design**](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/collaboration/design-your-process) mode is tailored to business users focused on modeling, sharing, and collaborating. [**Implement**](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/collaboration/implement-your-process) and [**Test**](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/validation/test-your-process) modes are tailored to developers focused on implementation and debugging.

When accessing a BPMN diagram for the [first time](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/modeling/model-your-first-diagram), the **Design** mode is the first selected option. To switch between modes, you can select one of the tabs on the left side of the modeling interface, above the diagram; any further selection is remembered and kept for the next sessions.

**Note**
When a process template is selected, the default mode is **Implement**.

### Modes and roles

| Role                | Description                                                                                                                                                                                           |
| :------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Workspace Admin** | Read/write access to all modes.                                                                                                                                                                       |
| **Editor**          | Read/write access to all modes.                                                                                                                                                                       |
| **Commenter**       | Read-only access to all modes. Can comment on diagrams. This role can be assigned to stakeholders who need to see the implementation properties without the ability to modify them.                   |
| **Viewers**         | Read-only access to all modes. Cannot comment on diagrams. This role is suitable for stakeholders who only need to view the process design and implementation without making any changes or comments. |

Read more about the [different roles and how to assign them](https://docs.camunda.io/docs/next/components/hub/organization/manage-workspaces/manage-workspace-members#workspace-roles).
