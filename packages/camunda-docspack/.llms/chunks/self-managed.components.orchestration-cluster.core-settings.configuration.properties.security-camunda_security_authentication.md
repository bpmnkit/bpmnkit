# Property reference — Security — `CAMUNDA_SECURITY_AUTHENTICATION`

| Property                                                        | Description                                                                                                                                                                                                                                                                                                              | Default value | Overridable per Physical Tenant |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------- | :------------------------------ |
| `CAMUNDA_SECURITY_AUTHENTICATION_AUTHENTICATIONREFRESHINTERVAL` | The interval at which the memberships (groups, roles, tenants, component authorizations) are refreshed for logged in users. Find more details in [webserver and security](https://docs.camunda.io/docs/next/self-managed/components/orchestration-cluster/core-settings/configuration/webserver#propagation-of-membership-changes-to-active-sessions). | `PT30S`       | Yes                             |
| `CAMUNDA_SECURITY_AUTHENTICATION_METHOD`                        | The authentication method to use. Options: `basic`, `oidc`.                                                                                                                                                                                                                                                              | `basic`       | No                              |
| `CAMUNDA_SECURITY_AUTHENTICATION_UNPROTECTEDAPI`                | If the API can be used without authentication.                                                                                                                                                                                                                                                                           | `false`       | No                              |
