# Best practices for custom-built element templates — Properties panel UI — Secret handling

- Follow the rules of the system you’re adding to.
- Do not save secret information in the JSON.
- Use the connectors' [secret handling](https://docs.camunda.io/docs/next/components/connectors/use-connectors/index#using-secrets).
