# Process modeling — Next steps

- [Modeling BPMN](https://docs.camunda.io/docs/next/components/modeler/bpmn/automating-a-process-using-bpmn) - Learn how to model an automated process in this tutorial using Camunda Hub with Camunda 8 SaaS.
- [Camunda Forms in Camunda Hub](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/modeling/utilize-forms) - Design and configure forms, and connect them to a user task or start event to implement a task form in your application.
- [DMN](https://docs.camunda.io/docs/next/components/modeler/dmn/dmn) - In DMN, model and execute decisions using the same language. As a business analyst, model the rules that lead to a decision in comprehensive tables, and execute these tables directly by a decision engine like Camunda.
- [Out-of-the-box connectors](https://docs.camunda.io/docs/next/components/connectors/use-connectors/configuring-out-of-the-box-connector) - Utilize pre-built connectivity with a number of outside systems via our [Camunda Marketplace](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/modeling/camunda-marketplace). Connectors are modular by nature, reusable, and accelerate automation across those systems.
- [Element templates](https://docs.camunda.io/docs/next/components/modeler/element-templates/about-templates) - Learn how to create element templates to extend the modeler.
- [Custom connectors](https://docs.camunda.io/docs/next/components/connectors/manage-connector-templates) - Learn how to build custom connectors alongside external systems based on our out-of-the-box connectors.
