# Property reference — Security — `CAMUNDA_SECURITY_INITIALIZATION_ROLES`

| Property                                                | Description                              | Default value | Overridable per Physical Tenant |
| ------------------------------------------------------- | ---------------------------------------- | ------------- | :------------------------------ |
| `CAMUNDA_SECURITY_INITIALIZATION_ROLES_0_ROLE_ID`       | The ID of this role.                     |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_ROLES_0_NAME`          | The name of this role.                   |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_ROLES_0_DESCRIPTION`   | The description of this role.            |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_ROLES_0_CLIENTS`       | The clients assigned to this role.       |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_ROLES_0_GROUPS`        | The groups assigned to this role.        |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_ROLES_0_MAPPING_RULES` | The mapping rules assigned to this role. |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_ROLES_0_USERS`         | The users assigned to this role.         |               | Yes                             |
