# Data Migrator — Cockpit plugin (experimental)

The [Cockpit plugin](https://docs.camunda.io/docs/next/guides/migrating-from-camunda-7/migration-tooling/data-migrator/cockpit-plugin) provides a web-based interface to view information about skipped and migrated data during the migration process (experimental).
