# Enable and connect — Connect an MCP client — Use with the MCP Client connectors

You can also connect to the MCP server from within a BPMN process using Camunda's [MCP Client connectors](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/agentic-ai-mcp-client). This allows an AI agent running in an agentic orchestration workflow to interact with Camunda's own operational data. For example, you can query incidents or start processes as part of an automated workflow.
