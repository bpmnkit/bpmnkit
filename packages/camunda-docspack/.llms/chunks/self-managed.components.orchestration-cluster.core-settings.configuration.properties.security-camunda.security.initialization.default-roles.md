# Property reference — Security — `camunda.security.initialization.default-roles`

| Property                                                                | Description                                  | Default value | Overridable per Physical Tenant |
| ----------------------------------------------------------------------- | -------------------------------------------- | ------------- | :------------------------------ |
| `camunda.security.initialization.default-roles.<role>.clients.[0]`      | Clients assigned to the `<role>` role.       |               | Yes                             |
| `camunda.security.initialization.default-roles.<role>.groups.[0]`       | Groups assigned to the `<role>` role.        |               | Yes                             |
| `camunda.security.initialization.default-roles.<role>.mappingrules.[0]` | Mapping rules assigned to the `<role>` role. |               | Yes                             |
| `camunda.security.initialization.default-roles.<role>.users.[0]`        | Users assigned to the `<role>` role.         |               | Yes                             |
