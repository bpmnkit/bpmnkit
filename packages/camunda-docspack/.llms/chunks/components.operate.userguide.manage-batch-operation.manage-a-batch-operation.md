# Manage batch operations — Manage a batch operation

To take an action on a batch operation:

1. In the left navigation, click **Operations > Batch operations**. For more details, see [monitor batch operations](https://docs.camunda.io/docs/next/components/operate/userguide/monitor-batch-operations).
2. From the **Batch Operations** page, click the operation you want to manage.
3. On the batch operation details page, on the right side of the page header, click an action, if available.
