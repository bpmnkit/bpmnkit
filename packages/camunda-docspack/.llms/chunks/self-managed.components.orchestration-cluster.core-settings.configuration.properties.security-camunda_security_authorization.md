# Property reference — Security — `CAMUNDA_SECURITY_AUTHORIZATION`

| Property                                  | Description                                                       | Default value | Overridable per Physical Tenant |
| ----------------------------------------- | ----------------------------------------------------------------- | ------------- | :------------------------------ |
| `CAMUNDA_SECURITY_AUTHORIZATIONS_ENABLED` | Enables authorization checks for Orchestration Cluster resources. | `true`        | Yes                             |
