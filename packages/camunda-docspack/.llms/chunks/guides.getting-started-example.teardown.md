# Run your first Spring Boot, Node.js, Python, or C# project with Camunda 8 — Teardown

You can stop Camunda 8 Run by executing:

    

### maclinux

```bash
./camunda-stop.sh

```

### windows

```bash
./camunda-stop.bat
````
