# Glossary — C — Child process instance

A [process instance](#process-instance) created by a [call activity](https://docs.camunda.io/docs/next/components/modeler/bpmn/call-activities/call-activities) in another process instance, the [parent process instance](#parent-process-instance).

See also: [Parent process instance](#parent-process-instance), [Root process instance](#root-process-instance)
