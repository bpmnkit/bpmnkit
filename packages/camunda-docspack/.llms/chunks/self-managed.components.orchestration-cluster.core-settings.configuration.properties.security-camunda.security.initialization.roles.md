# Property reference — Security — `camunda.security.initialization.roles`

| Property                                                 | Description                              | Default value | Overridable per Physical Tenant |
| -------------------------------------------------------- | ---------------------------------------- | ------------- | :------------------------------ |
| `camunda.security.initialization.roles.[0].roleId`       | The ID of this role.                     |               | Yes                             |
| `camunda.security.initialization.roles.[0].name`         | The name of this role.                   |               | Yes                             |
| `camunda.security.initialization.roles.[0].description`  | The description of this role.            |               | Yes                             |
| `camunda.security.initialization.roles.[0].clients`      | The clients assigned to this role.       |               | Yes                             |
| `camunda.security.initialization.roles.[0].groups`       | The groups assigned to this role.        |               | Yes                             |
| `camunda.security.initialization.roles.[0].mappingRules` | The mapping rules assigned to this role. |               | Yes                             |
| `camunda.security.initialization.roles.[0].users`        | The users assigned to this role.         |               | Yes                             |
