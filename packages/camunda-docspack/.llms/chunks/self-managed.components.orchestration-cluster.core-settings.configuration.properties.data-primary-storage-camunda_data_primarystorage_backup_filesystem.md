# Property reference — Data - primary storage — `CAMUNDA_DATA_PRIMARYSTORAGE_BACKUP_FILESYSTEM`

| Property                                                 | Description                                                    | Default value | Overridable per Physical Tenant |
| :------------------------------------------------------- | :------------------------------------------------------------- | :------------ | :------------------------------ |
| `CAMUNDA_DATA_PRIMARYSTORAGE_BACKUP_FILESYSTEM_BASEPATH` | Set the base path to store all related backup files in. | Null          | Yes                             |
