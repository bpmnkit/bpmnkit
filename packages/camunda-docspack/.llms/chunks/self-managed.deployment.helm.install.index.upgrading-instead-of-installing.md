# Install Camunda with Helm — Upgrading instead of installing

To move an existing deployment to 8.10, see [upgrade Camunda 8.9 to 8.10 using Helm](https://docs.camunda.io/docs/next/self-managed/upgrade/helm/890-to-8100). Upgrade in place first; adopting the split topology is a separate step, covered in [move from a combined release to the split topology](https://docs.camunda.io/docs/next/self-managed/upgrade/helm/combined-to-split-topology).
