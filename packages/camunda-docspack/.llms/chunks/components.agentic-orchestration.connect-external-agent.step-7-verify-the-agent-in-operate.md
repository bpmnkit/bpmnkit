# Connect an external agent — Step 7: Verify the agent in Operate

Start a process instance and [open it in Operate](https://docs.camunda.io/docs/next/components/operate/userguide/basic-operate-navigation). Select the agent element on the diagram to see the agent instance data you reported: its state, usage metrics, model, system prompt, tools, and conversation history grouped by loop iteration.

See [monitor your AI agents](https://docs.camunda.io/docs/next/components/agentic-orchestration/evaluate-agents/monitor-ai-agents) to learn how to inspect and debug AI agents in Operate.
