# Logical Tenants — Configuration and management

All Logical Tenant configuration and management pages are consolidated here. Each page focuses on a specific aspect:

### Deployment configuration

- [Configure Logical Tenants in Helm chart](https://docs.camunda.io/docs/next/self-managed/deployment/helm/configure/configure-logical-tenants). Set up multi-tenancy flags and prerequisites for Orchestration Cluster and Management Identity.

### Tenant initialization

- [Initialize tenants for Optimize](https://docs.camunda.io/docs/next/self-managed/components/management-identity/configuration/initialize-tenants). Programmatically create tenants at startup using configuration files or environment variables.

### Runtime management

- [Manage tenants in Identity](https://docs.camunda.io/docs/next/self-managed/components/management-identity/manage-tenants). Create, view, and manage tenants through the Identity UI. Assign users, groups, and applications.

### Component-specific setup

- [Optimize multi-tenancy](https://docs.camunda.io/docs/next/self-managed/components/optimize/configuration/multi-tenancy). Enable and configure multi-tenancy features specific to Optimize.
