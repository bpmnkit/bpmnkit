# Variable labeling — Limitations

Note that this feature is currently not supported in task analysis. This means that during task analysis, the original name of a variable will be displayed.


## Authentication

Every request requires [authentication](https://docs.camunda.io/docs/next/apis-tools/optimize-api/optimize-api-authentication).


## Method & HTTP target resource

POST `/api/public/variables/labels`


## Request headers

The following request headers must be provided with every variable labeling request:

| Header        | Constraints | Value                                              |
| ------------- | ----------- | -------------------------------------------------- |
| Authorization | REQUIRED    | [Authentication](https://docs.camunda.io/docs/next/apis-tools/optimize-api/optimize-api-authentication) |
