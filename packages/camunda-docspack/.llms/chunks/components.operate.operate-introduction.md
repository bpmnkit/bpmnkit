# Introduction to Operate

Operate is a tool managing, monitoring, and troubleshooting your processes.

Operate is a tool for monitoring and troubleshooting process instances running in [Zeebe](https://docs.camunda.io/docs/next/components/zeebe/zeebe-overview).

In addition to providing visibility into active and completed process instances, Operate can also:

- Carry out key operations such as resolving [incidents](https://docs.camunda.io/docs/next/components/operate/userguide/resolve-incidents-update-variables) and updating process variables.
- Retry or cancel [many process instances at once](https://docs.camunda.io/docs/next/components/operate/userguide/selections-operations).
- [Delete finished instances](https://docs.camunda.io/docs/next/components/operate/userguide/delete-finished-instances) and [resources](https://docs.camunda.io/docs/next/components/operate/userguide/delete-resources).
- [Modify](https://docs.camunda.io/docs/next/components/operate/userguide/process-instance-modification) an active process instance to allow execution to continue.
- [Batch move](https://docs.camunda.io/docs/next/components/operate/userguide/process-instance-batch-modification) active process instances to allow execution to continue.
