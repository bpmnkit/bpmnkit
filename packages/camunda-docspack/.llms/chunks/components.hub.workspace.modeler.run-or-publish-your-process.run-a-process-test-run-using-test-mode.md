# Run or publish your process — Run a process — Test run using Test mode

Before you publish or run a process, you can test it manually using the [Test mode](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/validation/test-your-process). With the Test mode, you can build and test your process iteratively in small steps. To enter the Test mode, click the Test tab in the top left corner of the modeling screen.
