# Processes MCP Server — Authentication

The Processes MCP Server uses the same authentication model as the [Orchestration Cluster REST API](https://docs.camunda.io/docs/next/apis-tools/orchestration-cluster-api-rest/orchestration-cluster-api-rest-authentication). OAuth tokens obtained for the REST API work without changes.

For the full authentication reference, including SaaS and Self-Managed setup, see [Authentication](https://docs.camunda.io/docs/next/apis-tools/orchestration-cluster-api-rest/orchestration-cluster-api-rest-authentication).
