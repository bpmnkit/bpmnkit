# Camunda 8 SaaS — Sign up — Deployment

You can configure a number of deployment options to meet your specific business and hosting requirements. For example, you can choose where to host your data and what level of data encryption to use.

| Deployment option                                                                      | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| :------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Cluster](https://docs.camunda.io/docs/next/components/concepts/clusters)                                            | Configure the cluster [type](https://docs.camunda.io/docs/next/components/concepts/clusters#cluster-type) and [size](https://docs.camunda.io/docs/next/components/concepts/clusters#cluster-size) to meet your organization's availability and scalability needs, and to provide control over cluster performance and [availability and uptime](https://docs.camunda.io/docs/next/components/concepts/clusters#cluster-availability-and-uptime).To learn more about choosing your cluster size, see [sizing your runtime environment](https://docs.camunda.io/docs/next/components/best-practices/architecture/sizing-your-environment).                                                                                                                                                              |
| [Region](https://docs.camunda.io/docs/next/components/saas/regions)                                                  | Choose the region and type of hosting you want to use for your clusters. GCP and AWS region hosting options are available.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| [Encryption at rest](https://docs.camunda.io/docs/next/components/saas/encryption-at-rest)                           | Cluster data is encrypted at rest to provide data security and protection.By default, Camunda 8 SaaS GCP and AWS cluster data at rest is protected with a provider-managed encryption key using GCP encryption. The encryption key is owned and managed by GCP.Enterprise customers requiring a higher level of protection can select a dedicated Camunda-managed software or hardware (HSM) encryption key when creating a new GCP cluster. The encryption key is managed by Camunda using Google Cloud Key Management Service (KMS).Camunda-managed encryption is not currently supported for AWS region clusters. |
| [Backups](https://docs.camunda.io/docs/next/components/saas/backups)                                                 | Back up the state of all Camunda 8 components (Zeebe, Operate, Tasklist, and Optimize) on a regular basis and with zero downtime. In case of failures that lead to data loss, you can restore the cluster from a backup. See [backup and restore overview](https://docs.camunda.io/docs/next/components/saas/backup-restore-overview).                                                                                                                                                                                                                                                                                                                                                                                    |
| [Auto-updates](https://docs.camunda.io/docs/next/components/saas/auto-updates)                                       | Camunda 8 SaaS customers can enable auto-updates. When enabled, the cluster is updated once a new patch release is available.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| [Secure connectivity (AWS PrivateLink)](https://docs.camunda.io/docs/next/components/saas/secure-connectivity/index) | Enable private inbound connectivity from your VPC to AWS-hosted Orchestration Clusters using AWS PrivateLink. Available for Enterprise plans.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
