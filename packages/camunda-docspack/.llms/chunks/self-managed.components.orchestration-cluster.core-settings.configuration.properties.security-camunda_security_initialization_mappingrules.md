# Property reference — Security — `CAMUNDA_SECURITY_INITIALIZATION_MAPPINGRULES`

| Property                                                       | Description                                  | Default value | Overridable per Physical Tenant |
| -------------------------------------------------------------- | -------------------------------------------- | ------------- | :------------------------------ |
| `CAMUNDA_SECURITY_INITIALIZATION_MAPPINGRULES_0_CLAIMNAME`     | The claim of the first mapping rule.         |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_MAPPINGRULES_0_CLAIMVALUE`    | The claim's value of the first mapping rule. |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_MAPPINGRULES_0_MAPPINGRULEID` | The id of the first mapping rule.            |               | Yes                             |
