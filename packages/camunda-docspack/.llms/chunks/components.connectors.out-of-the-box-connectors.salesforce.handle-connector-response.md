# Salesforce connector — Handle connector response

The **Salesforce connector** is a protocol connector, meaning it is built on top of the **HTTP REST connector**. Therefore,
handling response is still applicable [as described](https://docs.camunda.io/docs/next/components/connectors/protocol/rest#response).
