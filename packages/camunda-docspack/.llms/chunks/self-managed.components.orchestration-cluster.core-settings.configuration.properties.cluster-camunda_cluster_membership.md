# Property reference — Cluster — `CAMUNDA_CLUSTER_MEMBERSHIP`

| Property                                       | Description                                                                                                                                                                                                                                                           | Default value | Overridable per Physical Tenant |
| :--------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------ | :------------------------------ |
| `CAMUNDA_CLUSTER_MEMBERSHIP_BROADCASTUPDATES`  | Configure whether to broadcast member updates to all members.If set to false, updates are gossiped among members.If set to true, network traffic may increase but it can reduce the time to detect membership changes. | `true`        | No                              |
| `CAMUNDA_CLUSTER_MEMBERSHIP_BROADCASTDISPUTES` | Configure whether to broadcast disputes to all members.If set to true, network traffic may increase but it can reduce the time to detect membership changes.                                                                               | `true`        | No                              |
| `CAMUNDA_CLUSTER_MEMBERSHIP_NOTIFYSUSPECT`     | Configure whether to notify a suspect node on state changes.                                                                                                                                                                                                   | `false`       | No                              |
| `CAMUNDA_CLUSTER_MEMBERSHIP_PROBEINTERVAL`     | Sets the interval at which to probe a random member.                                                                                                                                                                                                           | `1s`          | No                              |
| `CAMUNDA_CLUSTER_MEMBERSHIP_PROBETIMEOUT`      | Sets the timeout for a probe response.                                                                                                                                                                                                                         | `100ms`       | No                              |
| `CAMUNDA_CLUSTER_MEMBERSHIP_SUSPECTPROBES`     | Sets the number of probes failed before declaring a member is suspect.                                                                                                                                                                                         | `3`           | No                              |
| `CAMUNDA_CLUSTER_MEMBERSHIP_FAILURETIMEOUT`    | Sets the timeout after which a suspect member is declared dead.                                                                                                                                                                                                | `10s`         | No                              |
| `CAMUNDA_CLUSTER_MEMBERSHIP_SYNCINTERVAL`      | Sets the interval at which this member synchronizes its membership information with a random member.                                                                                                                                                           | `10s`         | No                              |
| `CAMUNDA_CLUSTER_MEMBERSHIP_GOSSIPFANOUT`      | Sets the number of members to which membership updates are sent at each gossip interval.                                                                                                                                                                       | `2`           | No                              |
| `CAMUNDA_CLUSTER_MEMBERSHIP_GOSSIPINTERVAL`    | Sets the interval at which the membership updates are sent to a random member.                                                                                                                                                                                 | `250ms`       | No                              |
