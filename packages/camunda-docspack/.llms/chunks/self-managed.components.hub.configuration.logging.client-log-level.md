# Logging — Client log level

The `restapi` component also serves the client application running in the browser.
To control the verbosity of the client logs, adjust the environment variable `LOG_LEVEL_CLIENT`.

```properties
LOG_LEVEL_CLIENT=DEBUG
```

**Info**
For `LOG_LEVEL_*` options, see [understanding log levels](https://docs.camunda.io/docs/next/self-managed/operational-guides/monitoring/log-levels#understanding-log-levels).
