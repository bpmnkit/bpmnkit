# Install and start Camunda 8 Run — Shut down Camunda 8 Run

To shut down Camunda 8 Run and end all running processes, run the following command from the `c8run` directory:

### maclinux

```bash
./shutdown.sh
```

### windows

```bash
.\c8run.exe stop
```

For Docker Compose environments, use the stop commands in the [developer quickstart with Docker Compose](https://docs.camunda.io/docs/next/self-managed/quickstart/developer-quickstart/docker-compose).
