# Logical Tenants — Logical Tenants in Camunda Hub

If multi-tenancy is enabled, you provide a Logical Tenant when you [deploy to a target environment](https://docs.camunda.io/docs/next/components/hub/workspace/manage-projects/deploy-project#logical-tenants) in Camunda Hub. The Logical Tenant is separate from the [environment](https://docs.camunda.io/docs/next/components/concepts/environments), which is a Physical Tenant or a cluster.
