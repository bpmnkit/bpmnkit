# Manage environments — Jobs

The details of an environment summarize its jobs for the last 24 hours: the number of jobs that were created, completed, and not completed. For more information, see the [job dashboard](https://docs.camunda.io/docs/next/components/hub/organization/analyze-operations/job-dashboard).


## Workspaces assigned to an environment

The details of an environment list the workspaces that the environment is assigned to. Organization owners and admins can open a workspace from this list. An environment that isn't assigned to any workspace is shown as **Unassigned**.

To change the assignment, see [assign environments to a workspace](https://docs.camunda.io/docs/next/components/hub/organization/manage-environments/assign-environments).
