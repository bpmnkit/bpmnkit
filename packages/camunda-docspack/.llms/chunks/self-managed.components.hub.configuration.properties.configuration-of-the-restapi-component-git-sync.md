# Property reference — Configuration of the `restapi` component — Git Sync

Camunda Hub supports syncing files via [Git Sync](https://docs.camunda.io/docs/next/components/hub/workspace/manage-projects/git-sync). Provide the base URL for your provider if you are using a self-hosted GitLab, GitHub, or Azure DevOps Server instance.
