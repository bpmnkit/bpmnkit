# Property reference — System — `camunda.webapps`

#### `camunda.webapps.operate`

| Property                             | Description                                                              | Default value | Overridable per Physical Tenant |
| :----------------------------------- | :----------------------------------------------------------------------- | :------------ | :------------------------------ |
| `camunda.webapps.operate.enabled`    | Controls whether Operate is enabled in the Orchestration Cluster. | `true`        | Yes                             |
| `camunda.webapps.operate.ui-enabled` | Controls whether the Operate UI is enabled.                       | `true`        | Yes                             |

#### `camunda.webapps.tasklist`
