# Property reference — Processing — `CAMUNDA_PROCESSING`

| Property                                                            | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Default value | Overridable per Physical Tenant |
| :------------------------------------------------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------ | :------------------------------ |
| `CAMUNDA_PROCESSING_MAXCOMMANDSINBATCH`                             | Sets the maximum number of commands processed within one batch.The processor will process until no more follow-up commands are created by the initial command or the configured limit is reached.Can be set to 1 to disable batch processing.Must be a positive integer number.Note that the resulting batch may contain more entries than this limit because it includes follow-up events. If the resulting batch is too large (see maxMessageSize), processing will be rolled back and retried with a smaller maximum batch size.                                                                                                                                                                                                                                           | `100`         | Yes                             |
| `CAMUNDA_PROCESSING_SCHEDULEDTASKSCHECKINTERVAL`                    | Configures how often a partition leader checks for expired scheduled tasks (for example, due date checking).Use a lower interval to potentially decrease delays between requested and actual execution, but note that low values can create unnecessary load while idle; benchmark changes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `1s`          | Yes                             |
| `CAMUNDA_PROCESSING_SKIPPOSITIONS`                                  | Allows skipping certain commands by their position.This is intended for debugging and data recovery and is not recommended for production use.The value is a comma-separated list of positions to skip. Whitespace is ignored.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |               | Yes                             |
| `CAMUNDA_PROCESSING_ENGINE_DISTRIBUTION_MAXBACKOFFDURATION`         | Allows configuring the maximum backoff duration for command redistribution retries. The retry interval is doubled after each retry until it reaches this maximum duration.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `5m`          | Yes                             |
| `CAMUNDA_PROCESSING_ENGINE_DISTRIBUTION_REDISTRIBUTIONINTERVAL`     | Allows configuring command redistribution retry interval. This is the initial interval used when retrying command distributions that have not been acknowledged.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `10s`         | Yes                             |
| `CAMUNDA_PROCESSING_ENGINE_JOB_INCLUDEVARIABLESINJOBCOMPLETEDEVENT` | Specifies whether variables are included in the JobIntent.COMPLETED follow-up event.When set to false (default), the event is emitted without variables. This prevents ExceededBatchRecordSizeException when a job completes with very large variables. Without this setting, the JobIntent.COMPLETE command could be rejected and the job could time out.When set to true, variables are included in the event, matching the behavior in releases earlier than 8.10.Exporters or integrations that need completion variables can read them from the JobIntent.COMPLETE command record or the follow-up ProcessEvent.TRIGGERING event. Both records always include the variables regardless of this setting.        | `false`       | Yes                             |
| `CAMUNDA_PROCESSING_ENGINE_SECRETS_INTERVAL`                        | Sets the idle fallback cadence at which the broker checks for secret references that are waiting to be resolved.Resolution runs in the background, off the processing path, so a slow secret store cannot stall processing. Under a steady stream of pending references, wake-delay governs how quickly cycles repeat; this interval instead bounds how long a scheduler that has found nothing to resolve waits before checking again.The interval is an upper bound on the wait, not a fixed cadence. A cycle that reaches batch-resolution-limit and makes progress, or reaches its record batch capacity, schedules the next cycle immediately. While a store is in retry backoff, the next cycle is scheduled for that store's retry deadline when it falls sooner than this interval. | `5s`          | Yes                             |
| `CAMUNDA_PROCESSING_ENGINE_SECRETS_WAKEDELAY`                       | Sets how soon the next cycle runs after one that resolved a reference, or after an activation requested a resolution since the last cycle ran.Under a steady stream of pending references, this is the effective cadence: cycles run close to this delay apart rather than at interval, which only governs an idle scheduler's slower fallback cadence. A cycle that neither makes progress nor is woken backs off geometrically from this value up to interval instead of jumping straight there.Lower it to reduce activation latency under a steady load, at the cost of polling stores more often.                                                                                                                                                                                      | `50ms`        | Yes                             |
| `CAMUNDA_PROCESSING_ENGINE_SECRETS_BATCHRESOLUTIONLIMIT`            | Sets the maximum number of pending secret references the broker resolves in one cycle.References beyond the limit stay pending and are picked up by a later cycle, so the limit bounds the work per cycle rather than discarding anything. When a cycle reaches the limit, the next cycle starts immediately instead of waiting interval.Raise it to clear a large backlog faster, at the cost of more concurrent load on the secret stores.                                                                                                                                                                                                                                                                                                                                                             | `20`          | Yes                             |
| `CAMUNDA_PROCESSING_ENGINE_SECRETS_RETRYMAXATTEMPTS`                | Sets how many consecutive attempts the broker makes against an unavailable secret store before it stops retrying.The value counts the initial attempt and subsequent retries. At the default of 3, the broker tries the store once and retries twice. After the third failure, the broker fails every reference still pending for that store. Those failures raise an incident for the jobs waiting on them. Attempts are counted per store rather than per secret, and the count is held in memory only, so it resets when the broker restarts or the partition changes leader.A secret that the store reports as missing or forbidden is not retried at all, because that failure is permanent.                                                                                                        | `3`           | Yes                             |
| `CAMUNDA_PROCESSING_ENGINE_SECRETS_RETRYINITIALDELAY`               | Sets the delay before the first retry after a secret store becomes unavailable.For each subsequent attempt, the broker multiplies the delay by retry-backoff-factor, up to retry-max-delay.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `1s`          | Yes                             |
| `CAMUNDA_PROCESSING_ENGINE_SECRETS_RETRYBACKOFFFACTOR`              | Sets the multiplier applied to the retry delay after each consecutive secret store failure.A value of 1 keeps the delay constant at retry-initial-delay. Higher values increase the delay more quickly, up to retry-max-delay.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `2`           | Yes                             |
| `CAMUNDA_PROCESSING_ENGINE_SECRETS_RETRYMAXDELAY`                   | Sets the longest delay the broker waits between retries of an unavailable secret store.The delay grows from retry-initial-delay by retry-backoff-factor on each attempt and is capped at this value.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | `30s`         | Yes                             |
| `CAMUNDA_PROCESSING_ENABLEPRECONDITIONSCHECK`                       | Configures whether basic RocksDB operations (for example, insert/delete) should check preconditions (for example, key does not already exist when inserting).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | `false`       | Yes                             |
| `CAMUNDA_PROCESSING_ENABLEFOREIGNKEYCHECKS`                         | Configures whether inserting or updating key-value pairs in RocksDB should check that foreign keys exist.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `false`       | Yes                             |
| `CAMUNDA_PROCESSING_ENABLEYIELDINGDUEDATECHECKER`                   | Changes the due date timer checker behavior to yield to other processing steps when there are very many timers.This avoids worst-case situations where processing could be blocked for an indefinite amount of time and the node becomes unhealthy.Under sustained high load, yielding can cause activated timers to fall behind real time.                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `true`        | Yes                             |
| `CAMUNDA_PROCESSING_ENABLEASYNCMESSAGETTLCHECKER`                   | When enabled, the message TTL checker runs asynchronously to the engine stream processor.This can improve throughput/latency when many messages with a non-zero TTL are published. Test in non-production before enabling.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | `false`       | Yes                             |
| `CAMUNDA_PROCESSING_ENABLEASYNCTIMERDUEDATECHECKER`                 | When enabled, the due date checker runs asynchronously to the engine stream processor.This can improve throughput/latency when there are many timers. Test in non-production before enabling.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | `false`       | Yes                             |
| `CAMUNDA_PROCESSING_ENABLESTRAIGHTTHROUGHPROCESSINGLOOPDETECTOR`    |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | `true`        | Yes                             |
| `CAMUNDA_PROCESSING_ENABLEMESSAGEBODYONEXPIRED`                     | Controls whether the full message body is included in the follow-up event when a message expires.When enabled, full message details can be exported by allowing Message.EXPIRED events, but it increases follow-up event size and can reduce how many messages can be expired per batch, potentially impacting performance and growth of expired message state.                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `false`       | Yes                             |
| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_ENABLED`                    | Enable request limiting for user requests (takes precedence over backpressure configuration).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | `true`        | Yes                             |
| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_WINDOWED`                   | Use windowed request limiting.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | `true`        | Yes                             |
| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_ALGORITHM`                  | The request limiting algorithm to use.Supported values: aimd, fixed, vegas, gradient, gradient2, legacy-vegas.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `aimd`        | Yes                             |
| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_AIMD_REQUESTTIMEOUT`        | AIMD: request timeout used by the algorithm.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `200ms`       | Yes                             |
| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_AIMD_INITIALLIMIT`          | AIMD: initial request limit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `100`         | Yes                             |
| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_AIMD_MINLIMIT`              | AIMD: minimum request limit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `1`           | Yes                             |
| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_AIMD_MAXLIMIT`              | AIMD: maximum request limit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `1000`        | Yes                             |
| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_AIMD_BACKOFFRATIO`          | AIMD: backoff ratio applied when backing off.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | `0.9`         | Yes                             |
| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_FIXED_LIMIT`                | Fixed: constant request limit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | `20`          | Yes                             |
| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_GRADIENT_MINLIMIT`          | Gradient: minimum request limit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `10`          | Yes                             |
| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_GRADIENT_INITIALLIMIT`      | Gradient: initial request limit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `20`          | Yes                             |
| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_GRADIENT_RTTTOLERANCE`      | Gradient: RTT tolerance used by the algorithm.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | `2.0`         | Yes                             |
| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_GRADIENT2_MINLIMIT`         | Gradient2: minimum request limit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | `10`          | Yes                             |
| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_GRADIENT2_INITIALLIMIT`     | Gradient2: initial request limit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | `20`          | Yes                             |

| `CAMUNDA_PROCESSING_FLOWCONTROL_REQUEST_VEGAS_ALPHA`                | Vegas: alpha parameter.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | `3`           | Yes                             |
