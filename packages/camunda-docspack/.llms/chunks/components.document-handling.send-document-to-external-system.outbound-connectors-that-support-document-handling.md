# Handle documents with outbound connectors — Outbound connectors that support document handling

| Connector                                                                                        | Support details                                                                                                                                                                                                                |
| ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Amazon Bedrock](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/amazon-bedrock)             | Supports consuming documents as inputs for conversations. Review the **Document** field in the properties panel where the document reference can be provided.                                                                  |
| [Amazon S3](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/amazon-s3)                       | Supports uploading documents from (or downloading documents to) the Camunda document store. Review the **Document** field in the properties panel where the document reference can be provided.                                |
| [Amazon Textract](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/amazon-textract)           | Supports reading the input document from the Camunda document store or an external URL (not inline content, which Textract cannot process), and returning the analysis result as a document reference instead of inline JSON.  |
| [Azure Blob Storage](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/azure-blob-storage)     | Supports uploading documents from (or downloading documents to) the Camunda document store. Review the **Document** field in the properties panel where the document reference can be provided.                                |
| [Box](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/box)                                   | Supports uploading documents from (or downloading documents to) the Camunda document store. Review the **Document** field in the properties panel where the document reference can be provided.                                |
| [Email](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/email-outbound#response-structure-1) | Supports sending Camunda documents as attachments, or storing incoming attachments as Camunda documents. These documents are automatically stored in the Camunda document store and available to map in the result expression. |
| [Google Drive](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/googledrive)                  | Supports document upload and download.                                                                                                                                                                                         |
| [Microsoft Teams](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/microsoft-teams)           | Supports sending documents to channels.                                                                                                                                                                                        |
| [REST](https://docs.camunda.io/docs/next/components/connectors/protocol/rest)                                                  | Supports storing the response as a document.                                                                                                                                                                                   |
| [SendGrid](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/sendgrid)                         | Provides attachment support.                                                                                                                                                                                                   |
| [Slack](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/slack)                               | Supports adding attachments and increasing template versions.                                                                                                                                                                  |
