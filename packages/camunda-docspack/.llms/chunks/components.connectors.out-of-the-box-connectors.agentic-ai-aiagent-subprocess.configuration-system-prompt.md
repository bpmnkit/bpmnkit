# AI Agent Sub-process connector — Configuration — System prompt

The **System Prompt** is a crucial part of the AI Agent connector configuration, as it defines the behavior and goal of the agent and instructs the LLM on how to act.

| Field         | Required | Description                                                                                                                                                                                                                                                            |
| :------------ | :------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| System prompt | Yes      | Specify a system prompt to define how the LLM should act.A minimal example system prompt is provided as a starting point for you to customize.You can use FEEL expressions to add dynamic values into the text. |
