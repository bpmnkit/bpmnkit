# Upgrade Helm chart

Upgrade to a more recent version of the Camunda Helm charts, and view configuration changes between versions.

Upgrade a Camunda 8 Self-Managed deployment installation using the official Camunda Helm charts.

**Caution: earlier versions**
If you are upgrading from a version earlier than 8.8, see [upgrading from an earlier version](https://docs.camunda.io/docs/next/self-managed/upgrade/index#upgrading-from-an-earlier-version).

**Note: Helm CLI support**
Camunda 8.10 (chart 15.x) supports Helm CLI v3 and v4.

Camunda recommends Helm CLI v4 and supports it for the full release cycles of Camunda 8.9 and 8.10. Camunda supports Helm CLI v3 (3.10 or later) until February 10, 2027, when upstream support ends. After February 10, 2027, Camunda no longer supports Helm CLI v3. Customers who continue to use Helm CLI v3 after that date do so at their own risk.

Switching CLIs does not require a release-state migration. See [Move from the Helm v3 CLI to v4](https://docs.camunda.io/docs/next/self-managed/deployment/helm/operational-tasks/moving-helm-v3-to-v4).
