# Property reference — Security — `camunda.security.initialization.groups`

| Property                                                  | Description                               | Default value | Overridable per Physical Tenant |
| --------------------------------------------------------- | ----------------------------------------- | ------------- | :------------------------------ |
| `camunda.security.initialization.groups.[0].groupId`      | The ID of this group.                     |               | Yes                             |
| `camunda.security.initialization.groups.[0].name`         | The name of this group.                   |               | Yes                             |
| `camunda.security.initialization.groups.[0].description`  | The description of this group.            |               | Yes                             |
| `camunda.security.initialization.groups.[0].clients`      | The clients assigned to this group.       |               | Yes                             |
| `camunda.security.initialization.groups.[0].mappingRules` | The mapping rules assigned to this group. |               | Yes                             |
| `camunda.security.initialization.groups.[0].users`        | The users assigned to this group.         |               | Yes                             |
