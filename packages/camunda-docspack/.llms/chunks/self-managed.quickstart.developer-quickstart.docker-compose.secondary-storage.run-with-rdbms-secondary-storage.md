# Configure secondary storage with Docker Compose — Run with RDBMS secondary storage

The following examples run each supported RDBMS backend as a separate Docker Compose service. Use them for local development and evaluation. Review the [RDBMS support policy](https://docs.camunda.io/docs/next/self-managed/concepts/databases/relational-db/rdbms-support-policy#scope-and-applicability) before you plan another deployment type.
