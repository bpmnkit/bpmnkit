# Property reference — Cluster — `CAMUNDA_CLUSTER_PARTITIONING`

| Property                                                          | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Default value | Overridable per Physical Tenant |
| :---------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------ | :------------------------------ |
| `CAMUNDA_CLUSTER_PARTITIONING_SCHEME`                             | Configures how partitions are distributed across brokers (the partitioning scheme). Available options are ROUND_ROBIN, FIXED, and ZONE_AWARE.When using FIXED, the broker-to-partition mapping must be specified under camunda.cluster.partitioning.fixed.When using ZONE_AWARE, the zones must be specified under camunda.cluster.partitioning.zone-aware.zones. | `ROUND_ROBIN` | No                              |
| `CAMUNDA_CLUSTER_PARTITIONING_FIXED_0_PARTITIONID`                | Partition ID entry used when camunda.cluster.partitioning.scheme is set to FIXED.                                                                                                                                                                                                                                                                                                                                                                | `1`           | No                              |
| `CAMUNDA_CLUSTER_PARTITIONING_FIXED_0_NODES_0_NODESID`            | Broker node ID for a fixed partition mapping entry (used when camunda.cluster.partitioning.scheme is FIXED).                                                                                                                                                                                                                                                                                                                                     | `0`           | No                              |
| `CAMUNDA_CLUSTER_PARTITIONING_FIXED_0_NODES_0_PRIORITY`           | Priority value associated with a broker node in the fixed partitioning configuration.                                                                                                                                                                                                                                                                                                                                                                                      | `1`           | No                              |
| `CAMUNDA_CLUSTER_PARTITIONING_ZONEAWARE_ZONES_0_NAME`             | The name of the zone. Used when camunda.cluster.partitioning.scheme is set to ZONE_AWARE. Follows the same rules as CAMUNDA_CLUSTER_ZONE.                                                                                                                                                                                                                                                                                           | -             | No                              |
| `CAMUNDA_CLUSTER_PARTITIONING_ZONEAWARE_ZONES_0_NUMBEROFBROKERS`  | The total number of brokers deployed in this zone.                                                                                                                                                                                                                                                                                                                                                                                                                         | -             | No                              |
| `CAMUNDA_CLUSTER_PARTITIONING_ZONEAWARE_ZONES_0_NUMBEROFREPLICAS` | The number of replicas for each replication group in this zone.                                                                                                                                                                                                                                                                                                                                                                                                            | -             | No                              |
| `CAMUNDA_CLUSTER_PARTITIONING_ZONEAWARE_ZONES_0_PRIORITY`         | The priority of the zone. Higher priorities translate to higher Raft election priorities, skewing partition leaders toward the highest-priority zone.                                                                                                                                                                                                                                                                                                                      | -             | No                              |
