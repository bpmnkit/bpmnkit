# Track catalog asset usage

See which catalog assets are outdated and which workspaces and projects still use an older version, so you can prioritize migrations.

See which catalog assets are outdated and which workspaces and projects still use an older version, so you can prioritize migrations.


## Prerequisites

To open the **Asset usage** tab, you must have an **Org Admin** or **Org Owner** role in your organization, and your organization must have at least one [published catalog asset](https://docs.camunda.io/docs/next/components/hub/organization/manage-catalog/getting-started). Without a published asset, the catalog shows only the setup instructions and no tabs.
