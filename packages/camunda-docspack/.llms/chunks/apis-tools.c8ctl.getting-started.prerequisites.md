# c8ctl CLI — Prerequisites

- **Node.js ≥ 22.18.0** (required for native TypeScript support)


## Install

Install `c8ctl` globally from npm:

```bash
npm install @camunda8/cli -g
```

After installation, both `c8ctl` and `c8` are available as commands in your terminal.


## Quick start with a local cluster

`c8ctl` includes a built-in `cluster` command that downloads and manages a local [Camunda 8 Run](https://docs.camunda.io/docs/next/self-managed/quickstart/developer-quickstart/c8run) instance. This is the fastest way to get a cluster running for development.
