# Property reference — API - gRPC — `camunda.api.grpc`

| Property                                    | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Default value | Overridable per Physical Tenant |
| :------------------------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------ | :------------------------------ |
| `camunda.api.grpc.address`                  | Set the address the gateway binds to.                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `0.0.0.0`     | No                              |
| `camunda.api.grpc.port`                     | Set the port the gateway binds to.                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `26500`       | No                              |
| `camunda.api.grpc.min-keep-alive-interval`  | Set the minimum keep alive interval.This setting specifies the minimum accepted interval between keep alive pings.This value must be specified as a positive integer followed by 's' for seconds, 'm' for minutes or 'h' for hours.                                                                                                                                                                                                                                            | `30s`         | No                              |
| `camunda.api.grpc.max-message-size`         | Set the maximum size of the incoming and outgoing messages (that is, commands and events).                                                                                                                                                                                                                                                                                                                                                                                                                | `4MB`         | No                              |
| `camunda.api.grpc.max-connection-age`       | Set the maximum age of a gRPC connection before the gateway proactively closes it (via GOAWAY), forcing the client to reconnect.This lets client-side load balancing pick a different node, keeping request distribution more even, and forces a refresh of the client's name resolution so nodes that weren't yet available when the client's original connections were established can still be discovered.If unset, the gateway keeps gRPC's own default of an unbounded connection age. | Null          | No                              |
| `camunda.api.grpc.max-connection-age-grace` | Set the grace period, after the maximum connection age elapses, during which existing calls on the connection may finish before it's forcibly terminated. Only takes effect when the maximum connection age is set.If unset, the gateway keeps gRPC's own default of an infinite grace period.                                                                                                                                                                                                     | Null          | No                              |
| `camunda.api.grpc.management-threads`       | Set the number of threads the gateway will use to communicate with the broker cluster.                                                                                                                                                                                                                                                                                                                                                                                                                    | `1`           | No                              |
