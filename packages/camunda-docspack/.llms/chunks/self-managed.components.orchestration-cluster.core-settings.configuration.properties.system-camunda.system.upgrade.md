# Property reference — System — `camunda.system.upgrade`

| Property                                      | Description                                                                                                                                                                                                                                                                             | Default value | Overridable per Physical Tenant |
| :-------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------ | :------------------------------ |
| `camunda.system.upgrade.enable-version-check` | Controls whether the version compatibility check is enforced during migration.Use this to test migration logic with snapshot or alpha versions.The default value is `true`, which means you cannot migrate to incompatible versions such as `SNAPSHOT` or `alpha`. | `true`        | No                              |
