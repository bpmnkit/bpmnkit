# System requirements — Generated solutions

Solutions generated by ProcessOS Harness use the following technologies.

| Component         | Technology                                                                                                    |
| ----------------- | ------------------------------------------------------------------------------------------------------------- |
| Workers           | Target SDKs: Spring Boot; TypeScript; Python                                                                  |
| Camunda artifacts | `.bpmn`, `.dmn`, and `.form` files for the latest Camunda 8 version.                                          |
| AI platforms      | As supported by [agentic orchestration](https://docs.camunda.io/docs/next/components/agentic-orchestration/agentic-orchestration-overview). |

TypeScript and Python are also fully supported worker targets, described in [generate Camunda artifacts](https://docs.camunda.io/docs/next/components/process-os-harness/run-a-project/artifact-generation#choose-a-target-sdk).
