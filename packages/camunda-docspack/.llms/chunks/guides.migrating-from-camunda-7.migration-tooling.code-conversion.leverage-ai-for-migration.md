# Code Conversion — Leverage AI for migration

Use the [Camunda migration agent skill](https://docs.camunda.io/docs/next/guides/migrating-from-camunda-7/migration-tooling/index#agentic-migration) to migrate Java code. The skill inventories your source code, then lets you select an AI-first, pattern-guided path or an optional recipe-assisted path.

[Set up and run the skill](https://docs.camunda.io/docs/next/guides/migrating-from-camunda-7/migration-tooling/index#set-up-and-run) from your Camunda 7 project directory. Use a capable coding model and review every conversion. Before migrating a broad codebase, compare both Java paths with representative code.
