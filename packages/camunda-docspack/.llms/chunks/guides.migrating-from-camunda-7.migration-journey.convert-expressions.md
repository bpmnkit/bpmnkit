# Migration journey — Convert expressions

Your models might contain JUEL expressions, which are not supported in Camunda 8.

Simple expressions are directly converted by the [Migration Analyzer](https://docs.camunda.io/docs/next/guides/migrating-from-camunda-7/migration-tooling/index#expression-conversion). You can also use the [FEEL Copilot](https://docs.camunda.io/docs/next/components/early-access/alpha/feel-copilot/feel-copilot) to rewrite more complex expressions for you.

Check the [code conversion patterns section](https://docs.camunda.io/docs/next/guides/migrating-from-camunda-7/migration-tooling/code-conversion) for more complicated scenarios.
