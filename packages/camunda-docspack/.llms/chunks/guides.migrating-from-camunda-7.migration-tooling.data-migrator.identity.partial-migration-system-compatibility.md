# Identity — Partial migration — `System` compatibility

| C7 Permission | Migration supported | C8 Permission equivalent                                 |
| ------------- | ------------------- | -------------------------------------------------------- |
| `READ`        | Yes                 | `READ`, `READ_USAGE_METRIC`                              |
| `SET`         | No                  | -                                                        |
| `DELETE`      | No                  | -                                                        |
| `ALL`         | Yes                 | `READ`, `READ_USAGE_METRIC`, `UPDATE`, `READ_JOB_METRIC` |
