# Settings — Settings JSON file

Your settings are saved in a `settings.json` file in the [user data directory](https://docs.camunda.io/docs/next/components/modeler/desktop-modeler/search-paths/search-paths#user-data-directory).

**Note**
Only the settings you have changed are stored in this file.
