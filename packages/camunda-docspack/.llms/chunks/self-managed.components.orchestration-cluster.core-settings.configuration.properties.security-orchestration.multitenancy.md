# Property reference — Security — `orchestration.multitenancy`

| Property                                    | Description                                                                                                 | Default value |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ------------- |
| `orchestration.multitenancy.checks.enabled` | **Deprecated in chart 15.x.** Enables multi-tenancy checks. This requires the API to be protected.          | `false`       |
| `orchestration.multitenancy.api.enabled`    | **Deprecated in chart 15.x.** Enables the multi-tenancy API and UI independently from multi-tenancy checks. | `true`        |
