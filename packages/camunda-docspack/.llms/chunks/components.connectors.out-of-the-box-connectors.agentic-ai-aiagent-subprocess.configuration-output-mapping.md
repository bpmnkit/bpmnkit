# AI Agent Sub-process connector — Configuration — Output mapping

Specify the process variables that you want to map and export the AI Agent connector response into.

| Field           | Required | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| :-------------- | :------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Result variable | Yes      | The result of the AI Agent connector is a context containing the following fields, depending on how the [Response](#response) is configured. Set this to a unique value for every agent in your process to avoid interference between agents.`context`: The updated **agent context** if the **Include agent context** option is enabled.`responseText`: The last response text provided by the LLM if the **Response Format** is set to `Text`.`responseJson`: The last response text provided by the LLM, parsed as a JSON object if the **Response Format** is set to `JSON` or if the **Parse text as JSON** option is enabled.`responseMessage`: The assistant message provided by the LLM if the **Include assistant message** option is enabled. |
