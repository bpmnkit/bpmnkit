# View Hub dashboard

Use the Hub dashboard to view clusters, alerts, recent activity, instances, and more.

Use the Hub dashboard to view organization activities at a high level.


## About

From the Hub dashboard, you can view:

- Number of users, task users, clusters, and Admin API credentials
- [Usage alerts](https://docs.camunda.io/docs/next/components/hub/organization/manage-organization-settings/usage-alerts)
- [Recent activity](https://docs.camunda.io/docs/next/components/hub/organization/manage-organization-settings/view-organization-activity)
- [Clusters](https://docs.camunda.io/docs/next/components/hub/organization/manage-clusters/manage-cluster#view-clusters)
- [Decision instance usage](https://docs.camunda.io/docs/next/components/hub/organization/manage-organization-settings/usage-history)
- [Process instance usage](https://docs.camunda.io/docs/next/components/hub/organization/manage-organization-settings/usage-history)


## View the dashboard

To view the Hub dashboard, click **Console**.
