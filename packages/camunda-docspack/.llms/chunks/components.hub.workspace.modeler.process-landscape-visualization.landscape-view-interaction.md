# Visualize the process landscape — Landscape view interaction

You can interact with the process landscape view in a number of ways.

### View BPMN file information

Click any node to view the information for the selected BPMN file, including the latest version of the process on the sidebar.

**Note**
For projects, version tags represent a unified "versioned" snapshot of all project files rather than separate versions for each file (as with simple BPMN files).

### Search

You can search the process landscape for a specific BPMN file.

1. Press `Ctrl+F` or `⌘+F` combination to initialize search.
1. Enter the name or identifier of the BPMN file you want to search for and highlight.

### Highlight paths

Click a node or connection to highlight the entire hierarchy of related connections.
