# Document automation

Document automation allows you to extract data from complex documents based on one or more linked document extraction projects.

**Info**
Document automation has been superseded by [document classification](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/idp/idp-document-classification) templates, which use LLMs to automatically classify documents by type.

To learn more, see [document classification](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/idp/idp-document-classification).
