# Camunda 8 reference architectures — Architecture — Orchestration Cluster vs Camunda Hub (2)

For production environments, use an external [identity provider](https://docs.camunda.io/docs/next/self-managed/deployment/helm/configure/authentication-and-authorization/external-oidc-provider) to connect both environments.
