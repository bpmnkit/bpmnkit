## Download the Getting Started Package

Download the Getting Started Package from [Camunda Downloads](https://docs.camunda.io/docs/next/downloads).

The starter package includes the following components:

- [Camunda 8 Run](https://docs.camunda.io/docs/next/self-managed/quickstart/developer-quickstart/c8run) – A simplified, single-application Camunda configuration for a local development environment.
- [Desktop Modeler](https://docs.camunda.io/docs/next/components/modeler/desktop-modeler/index) – An application for modeling BPMN, DMN, and Forms.
- [Getting started project](https://github.com/camunda/camunda-8-get-started) – An example project with a simple BPMN process and workers in Java, JavaScript, Python, or C#.

All of these components are included in the starter package. You do not need to download them separately. The links above are provided for additional information.
