# Connectors

Run your process test with connectors to verify the integration with external systems or the configuration of the connector tasks in your processes.

You can run your process test with [Connectors](https://docs.camunda.io/docs/next/components/connectors/introduction) to verify the integration with external systems or the configuration of the connector tasks in your processes.

For more unit-focused tests, mock the interaction; for example,
by [completing connector jobs](https://docs.camunda.io/docs/next/apis-tools/testing/utilities#mock-job-workers) with an expected result.

**Note**
The instructions on this page are based on the default Testcontainer runtime. If you are using a remote runtime, consult
the relevant distribution documentation, such
as [Camunda 8 Run](https://docs.camunda.io/docs/next/self-managed/quickstart/developer-quickstart/c8run/configuration#use-built-in-and-custom-connectors).
