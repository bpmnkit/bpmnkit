# Property reference — Security — `CAMUNDA_SECURITY_INITIALIZATION_USERS`

| Property                                           | Description                          | Default value | Overridable per Physical Tenant |
| -------------------------------------------------- | ------------------------------------ | ------------- | :------------------------------ |
| `CAMUNDA_SECURITY_INITIALIZATION_USERS_0_EMAIL`    | The email address of the first user. |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_USERS_0_NAME`     | The name of the first user.          |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_USERS_0_PASSWORD` | The password of the first user.      |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_USERS_0_USERNAME` | The username of the first user.      |               | Yes                             |
