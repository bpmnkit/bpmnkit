# Property reference — Security — `camunda.security.initialization.tenants`

| Property                                                   | Description                                | Default value | Overridable per Physical Tenant |
| ---------------------------------------------------------- | ------------------------------------------ | ------------- | :------------------------------ |
| `camunda.security.initialization.tenants.[0].tenantId`     | The ID of this tenant.                     |               | Yes                             |
| `camunda.security.initialization.tenants.[0].name`         | The name of this tenant.                   |               | Yes                             |
| `camunda.security.initialization.tenants.[0].description`  | The description of this tenant.            |               | Yes                             |
| `camunda.security.initialization.tenants.[0].clients`      | The clients assigned to this tenant.       |               | Yes                             |
| `camunda.security.initialization.tenants.[0].groups`       | The groups assigned to this tenant.        |               | Yes                             |
| `camunda.security.initialization.tenants.[0].mappingRules` | The mapping rules assigned to this tenant. |               | Yes                             |
| `camunda.security.initialization.tenants.[0].roles`        | The roles assigned to this tenant.         |               | Yes                             |
| `camunda.security.initialization.tenants.[0].users`        | The users assigned to this tenant.         |               | Yes                             |
