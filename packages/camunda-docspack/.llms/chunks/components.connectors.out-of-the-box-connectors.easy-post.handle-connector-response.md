# EasyPost connector — Handle connector response

The **EasyPost connector** is a protocol connector, meaning it is built on top of the **HTTP REST connector**, therefore
handling response is still applicable [as described](https://docs.camunda.io/docs/next/components/connectors/protocol/rest#response).
