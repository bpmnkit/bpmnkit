# Glossary — C — Connector template

A [connector template](https://docs.camunda.io/docs/next/components/connectors/custom-built-connectors/connector-templates) is a type of element template used to configure connectors in [Camunda Hub](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/index) and [Desktop Modeler](https://docs.camunda.io/docs/next/components/modeler/desktop-modeler/index). Templates define UI fields, metadata, and bindings required for connector operations. Camunda Hub and Desktop Modeler internally label all templates as element templates, but connector templates are the subset specifically used to configure connectors.
