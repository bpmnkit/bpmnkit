# User task access restrictions were removed

User task access restrictions were removed with Tasklist V1 in Camunda 8.10.

User task access restrictions were removed in Camunda 8.10 together with Tasklist V1.

For the release-level summary of this removal, see the [8.10 release announcement](https://docs.camunda.io/docs/next/reference/announcements-release-notes/8100/8100-announcements#removal-of-legacy-apis-tasklist-v1-dependent-features-and-zeebe-process-test).

Use [user task authorization](https://docs.camunda.io/docs/next/components/tasklist/user-task-authorization) and [authorization-based access control](https://docs.camunda.io/docs/next/components/concepts/access-control/authorizations) for current Tasklist access control.

If you are migrating from an older installation, review [Tasklist API changes](https://docs.camunda.io/docs/next/components/tasklist/api-versions) to understand which legacy V1 features were removed.
