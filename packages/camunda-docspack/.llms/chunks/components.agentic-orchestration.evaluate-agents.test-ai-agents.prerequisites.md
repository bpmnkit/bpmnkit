# Test your AI agents with CPT — Prerequisites

- You use Camunda 8.9+.
- You use the Camunda Process Test Spring Boot Starter.
- You have [Camunda Process Test set up](https://docs.camunda.io/docs/next/apis-tools/testing/getting-started).
- You have downloaded the [AI Agent Chat With Tools](https://marketplace.camunda.com/en-US/apps/587865) process to your local machine.

**Important**
This guide is a follow-up to [build your first AI agent](https://docs.camunda.io/docs/next/guides/getting-started-agentic-orchestration), in which you use the same example AI agent process. We recommend completing that guide first. However, you can also apply this guide to other AI agent process implementations.
