# Configure secondary storage in Camunda 8 Run

Configure H2, external relational databases, or Elasticsearch as secondary storage in Camunda 8 Run.

<!-- markdownlint-disable MD033 MD036 -->

Camunda 8 Run supports multiple [secondary storage](https://docs.camunda.io/docs/next/reference/glossary#secondary-storage) options. **H2 is the default secondary storage** for lightweight Camunda 8 Run setups and quickstarts. If you need full-text indexing, search, or advanced analytics, use an external Elasticsearch instance.
