# Use cases

Learn how to upload a document to a BPMN process, display and download a document in a user task, and send a document to an external system via a connector.

Offering robust [document handling](https://docs.camunda.io/docs/next/components/document-handling/getting-started) capabilities within Camunda 8, users can efficiently manage large volumes of binary data such as PDFs and images across both development and production environments in SaaS and Self-Managed.

In this section we will cover three main use cases:

- [Upload a document to a BPMN process](https://docs.camunda.io/docs/next/components/document-handling/upload-document-to-bpmn-process)
- [Display and download a document](https://docs.camunda.io/docs/next/components/document-handling/display-and-download-document)
- [Send a document to an external system via a connector](https://docs.camunda.io/docs/next/components/document-handling/send-document-to-external-system)
