# Expose a process as an MCP tool — Step 5: Connect an MCP client

Connect any MCP-compliant client to the Processes MCP Server.

See [Enable and connect](https://docs.camunda.io/docs/next/apis-tools/processes-mcp/processes-mcp-setup) for endpoint URLs, authentication options, and other configuration details.


## Step 6: Verify

After deployment, you can verify that your process is registered as an MCP tool in the [Orchestration Cluster admin UI](https://docs.camunda.io/docs/next/components/admin/admin-introduction#open-admin). See [MCP processes](https://docs.camunda.io/docs/next/self-managed/components/orchestration-cluster/admin/mcp-processes) to learn how.
