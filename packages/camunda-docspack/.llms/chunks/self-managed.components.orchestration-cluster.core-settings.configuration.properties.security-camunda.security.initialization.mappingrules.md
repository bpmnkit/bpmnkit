# Property reference — Security — `camunda.security.initialization.mappingrules`

| Property                                                           | Description                                  | Default value | Overridable per Physical Tenant |
| ------------------------------------------------------------------ | -------------------------------------------- | ------------- | :------------------------------ |
| `camunda.security.initialization.mappingrules.[0].claim-name`      | The claim of the first mapping rule.         |               | Yes                             |
| `camunda.security.initialization.mappingrules.[0].claim-value`     | The claim's value of the first mapping rule. |               | Yes                             |
| `camunda.security.initialization.mappingrules.[0].mapping-rule-id` | The id of the first mapping rule.            |               | Yes                             |
