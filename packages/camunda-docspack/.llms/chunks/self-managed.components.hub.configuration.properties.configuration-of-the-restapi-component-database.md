# Property reference — Configuration of the `restapi` component — Database

Camunda Hub currently supports PostgreSQL, Oracle, Microsoft SQL Server (MSSQL), MySQL, MariaDB, and H2 as persistent data storage.

**Info: Oracle and MySQL driver**
The Oracle and MySQL drivers are not provided by default and must be downloaded and supplied for the application to load.
Refer to the [Oracle](https://docs.camunda.io/docs/next/self-managed/components/hub/configuration/database#oracle) and [MySQL](https://docs.camunda.io/docs/next/self-managed/components/hub/configuration/database#mysql) database configuration section for details.
