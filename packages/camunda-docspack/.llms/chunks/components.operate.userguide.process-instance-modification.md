# Modify a process instance

You may need to modify an active process instance to allow execution to continue.

Learn how to modify a process instance in Camunda 8 Operate.


## Overview

You may need to modify an active process instance to allow execution to continue. The execution may be stuck, and you may want to continue the execution on a different activity (i.e. skip or repeat activities).

**Note**
If an issue in process execution caused you to enter the wrong process branch instead of moving each process instance individually, use [process instance batch modification](https://docs.camunda.io/docs/next/components/operate/userguide/process-instance-batch-modification) instead to select multiple process instances and move them to the correct flow node in the process in a single operation.
