# Get started with human task orchestration — Additional resources and next steps

- Learn how to use [BPMN user tasks](https://docs.camunda.io/docs/next/components/modeler/bpmn/user-tasks/user-tasks) to route tasks to the right users.
- Learn how to [build more complex forms](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/modeling/utilize-forms) using the form editor.
- Learn how to write powerful [expressions](https://docs.camunda.io/docs/next/components/concepts/expressions) and utilize [variables](https://docs.camunda.io/docs/next/components/concepts/variables) to route complex process flows.
- Get an [introduction to Operate](https://docs.camunda.io/docs/next/components/operate/operate-introduction).
- Learn how to [set up Tasklist](https://docs.camunda.io/docs/next/components/tasklist/introduction-to-tasklist) for efficient task management.
- Explore start forms and attach the form directly to the start event for authenticated starts in Tasklist.
