# Migration journey

Get started with your migration by understanding the main steps involved in a successful migration journey.

Although migration projects differ in complexity, there is a common theme in how to approach the migration journey.


## Migration journeys

The complexity of Camunda-7-based solutions varies significantly. Solutions range from small implementations with [clean delegates](https://docs.camunda.io/docs/next/guides/migrating-from-camunda-7/migration-tooling/code-conversion) to large solutions with hundreds of processes using internal API hacks.

This guide covers two typical journeys - a simplified migration journey and an advanced migration journey.
