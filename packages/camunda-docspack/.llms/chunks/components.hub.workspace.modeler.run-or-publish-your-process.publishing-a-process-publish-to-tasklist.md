# Run or publish your process — Publishing a process — Publish to Tasklist

[Publishing a process to Tasklist](https://docs.camunda.io/docs/next/components/tasklist/userguide/using-tasklist#processes) makes it available to users through the web-based [Tasklist application](https://docs.camunda.io/docs/next/components/tasklist/introduction-to-tasklist).

To publish a process to Tasklist, you first need to [deploy](#deploy-a-process) it. Once the process is deployed, it will automatically appear in the Tasklist application, where users can start new instances of the process.
