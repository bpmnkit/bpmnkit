# Process modeling

Camunda offers a web-based modeler in Camunda Hub and Desktop Modeler to design and implement any executable process using BPMN.

Camunda provides modeling tools for designing and implementing executable diagrams with [BPMN](https://docs.camunda.io/docs/next/components/modeler/bpmn/bpmn), [DMN](https://docs.camunda.io/docs/next/components/modeler/dmn/dmn), and [Forms](https://docs.camunda.io/docs/next/components/modeler/forms/camunda-forms-reference).

Choose the modeler that best fits how you work:

- [Camunda Hub](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/index): Use Camunda's browser-based modeler in Hub to collaborate on diagrams in Camunda 8 SaaS or Self-Managed.
- [Desktop Modeler](https://docs.camunda.io/docs/next/components/modeler/desktop-modeler/index): Install the desktop application to model locally and integrate with your development environment.
