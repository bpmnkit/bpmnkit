# Upload a document to a BPMN process — Upload a document using the Orchestration Cluster REST API

You can also upload a document to your Camunda 8 cluster using the Orchestration Cluster REST API.

**Note**
This is currently supported for document stores of type: [AWS, GCP, in-memory (non-production), local (non-production)](https://docs.camunda.io/docs/next/self-managed/concepts/document-handling/configuration/index).

Learn more about [uploading a single document](https://docs.camunda.io/docs/next/apis-tools/orchestration-cluster-api-rest/specifications/create-document.api) and [uploading multiple documents](https://docs.camunda.io/docs/next/apis-tools/orchestration-cluster-api-rest/specifications/create-documents.api) using the Orchestration Cluster REST API.
