# Zeebe API (gRPC) — Key capabilities

- Activate jobs
- Create and cancel process instances
- Manage workflows and more

See [Zeebe API RPCs](https://docs.camunda.io/docs/next/apis-tools/zeebe-api/gateway-service) for all available operations. Additionally, review [technical error handling](https://docs.camunda.io/docs/next/apis-tools/zeebe-api/technical-error-handling) for a closer look at business logic errors, or [Postman](https://www.postman.com/camundateam/camunda-8-postman/collection/jzgs776/zeebe-api-grpc?action=share&creator=11465105) to experiment with the API.


## Authentication

Authentication for the Zeebe API (gRPC) depends on your environment and how you deploy Camunda 8. You can find more details in the [Authentication guide](https://docs.camunda.io/docs/next/apis-tools/zeebe-api/zeebe-api-authentication).
