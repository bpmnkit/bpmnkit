# Glossary — P — Process model

The BPMN representation of a [process](https://docs.camunda.io/docs/next/components/concepts/processes), created in a BPMN file (for example, in [Camunda Hub](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/index) or [Desktop Modeler](https://docs.camunda.io/docs/next/components/modeler/desktop-modeler/index)).

Identified by its **process ID** (`bpmn:process id` attribute).

A single BPMN file can contain multiple process models.
