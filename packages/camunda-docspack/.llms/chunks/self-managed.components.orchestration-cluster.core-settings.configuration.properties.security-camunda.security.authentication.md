# Property reference — Security — `camunda.security.authentication`

| Property                                                          | Description                                                                                                                                                                                                                                                                                                              | Default value | Overridable per Physical Tenant |
| ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------- | :------------------------------ |
| `camunda.security.authentication.authentication-refresh-interval` | The interval at which the memberships (groups, roles, tenants, component authorizations) are refreshed for logged in users. Find more details in [webserver and security](https://docs.camunda.io/docs/next/self-managed/components/orchestration-cluster/core-settings/configuration/webserver#propagation-of-membership-changes-to-active-sessions). | `PT30S`       | Yes                             |
| `camunda.security.authentication.method`                          | The authentication method to use. Options: `basic`, `oidc`.                                                                                                                                                                                                                                                              | `basic`       | No                              |
| `camunda.security.authentication.unprotected-api`                 | If the API can be used without authentication.                                                                                                                                                                                                                                                                           | `false`       | No                              |
