# Property reference — Security — `orchestration.security.authentication.oidc`

| Property                                                                  | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Default value           |
| ------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| `orchestration.security.authentication.oidc.type`                         | The OIDC provider flavor the chart assumes when it derives endpoint URLs and configures the other components. Options: `KEYCLOAK`, `MICROSOFT`, `GENERIC`. The chart value is empty by default and inherits from `global.identity.auth.type`, which is `KEYCLOAK`. This value is evaluated by the chart only; it does not map to a `camunda.security.*` application property. Must be uppercase: the chart passes it through unchanged and validates only `global.identity.auth.type`, so a lowercase value such as `keycloak` is accepted without a render error and the chart stops deriving the Keycloak authorization, token, and JWKS endpoint URLs. | `KEYCLOAK`              |
| `orchestration.security.authentication.oidc.clientId`                     | The client ID for OIDC authentication.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `orchestration`         |
| `orchestration.security.authentication.oidc.secret.inlineSecret`          | The client secret for OIDC authentication, as a plain-text value. Intended for non-production usage.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |                         |
| `orchestration.security.authentication.oidc.secret.existingSecret`        | The name of an existing Kubernetes Secret that holds the client secret. Must be set together with `existingSecretKey`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |                         |
| `orchestration.security.authentication.oidc.secret.existingSecretKey`     | The key within `existingSecret` that holds the client secret. Must be set together with `existingSecret`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |                         |
| `orchestration.security.authentication.oidc.issuer`                       | Sets the OIDC provider's issuer URI explicitly, from which the Orchestration Cluster discovers the provider's endpoints. Overrides `global.identity.auth.issuer`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |                         |
| `orchestration.security.authentication.oidc.authUrl`                      | Sets the OIDC provider's authorization endpoint URI explicitly. Only takes effect if neither `orchestration.security.authentication.oidc.issuer` nor `global.identity.auth.issuer` is set. Supports templating (for example, `{{ .Release.Name }}`).                                                                                                                                                                                                                                                                                                                                                                                                      |                         |
| `orchestration.security.authentication.oidc.jwksUrl`                      | Sets the OIDC provider's JWK Set URI explicitly. Only takes effect if neither `orchestration.security.authentication.oidc.issuer` nor `global.identity.auth.issuer` is set. Supports templating (for example, `{{ .Release.Name }}`).                                                                                                                                                                                                                                                                                                                                                                                                                     |                         |
| `orchestration.security.authentication.oidc.tokenUrl`                     | Sets the OIDC provider's token URI explicitly. Only takes effect if neither `orchestration.security.authentication.oidc.issuer` nor `global.identity.auth.issuer` is set. Supports templating (for example, `{{ .Release.Name }}`).                                                                                                                                                                                                                                                                                                                                                                                                                       |                         |
| `orchestration.security.authentication.oidc.redirectUrl`                  | **Deprecated in chart 15.x.** The URI for redirects from the OIDC provider to the Orchestration Cluster after user login. The chart appends `/sso-callback` to this value when it renders the `redirect-uri` property. Supports templating (for example, `{{ .Release.Name }}`). This single value sets three application properties — the login callback plus the Operate and Tasklist redirect roots — so see the [upgrade guide](https://docs.camunda.io/docs/next/self-managed/upgrade/helm/890-to-8100#deprecated-application-configuration-helm-keys) for the full mapping; setting only one of the three leaves them on different hosts.                                         | `http://localhost:8080` |
| `orchestration.security.authentication.oidc.usernameClaim`                | **Deprecated in chart 15.x.** The JWT claim that identifies a user. Extracted from a token, this claim value becomes the user's username. This setting is evaluated on any token-based access, regardless of the underlying OIDC/OAuth flow.                                                                                                                                                                                                                                                                                                                                                                                                              | `preferred_username`    |
| `orchestration.security.authentication.oidc.preferUsernameClaim`          | **Deprecated in chart 15.x.** Determines if a token that contains both the configured username claim and the configured client ID claim is treated as a user or as a client. If set to `true`, it is treated as a user. If set to `false`, it is treated as a client.                                                                                                                                                                                                                                                                                                                                                                                     | `false`                 |
| `orchestration.security.authentication.oidc.clientIdClaim`                | **Deprecated in chart 15.x.** The JWT claim that identifies a client. Extracted from a token, this claim value becomes the client ID. This setting is evaluated on any token-based access, regardless of the underlying OIDC/OAuth flow.                                                                                                                                                                                                                                                                                                                                                                                                                  | `client_id`             |
| `orchestration.security.authentication.oidc.groupsClaim`                  | **Deprecated in chart 15.x.** The JWT claim that contains a user's or client's groups. Expects an array of String values. If not set, groups can be managed in the Orchestration Cluster through its REST APIs.                                                                                                                                                                                                                                                                                                                                                                                                                                           |                         |
| `orchestration.security.authentication.oidc.audience`                     | The audience to validate in the OIDC token.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | `orchestration-api`     |
| `orchestration.security.authentication.oidc.scope`                        | **Deprecated in chart 15.x.** A list of scopes to request in the OIDC token. If empty, the application default (`openid, profile`) applies.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | `[]`                    |
| `orchestration.security.authentication.oidc.backwardsCompatibleAudiences` | **Deprecated in chart 15.x.** Additional audiences accepted when validating the OIDC token, alongside `audience` and the client ID. Only needed when upgrading from an earlier version that used a different audience. Its replacement, `camunda.security.authentication.oidc.audiences`, replaces the audience list rather than adding to it, so list the full default audience set alongside your own — see [backwards-compatible audiences replace the audience list](https://docs.camunda.io/docs/next/self-managed/upgrade/helm/890-to-8100#backwards-compatible-audiences-replace-the-audience-list).                                                                             | `[]`                    |
