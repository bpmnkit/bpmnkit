# Defining templates — Further reading

For detailed information about specific aspects of template development, see:

- **[Template metadata](https://docs.camunda.io/docs/next/components/modeler/element-templates/template-metadata)** - Learn more about template key-value pairs that help you version your template, make it discoverable, and allow you to define compatability.
- **[Template properties](https://docs.camunda.io/docs/next/components/modeler/element-templates/template-properties)** - The properties array is the heart of the element template. Here you can define what properties should be applied to the BPMN element and how these properties should be shown and validated in the properties panel.
- **[Example template](https://docs.camunda.io/docs/next/components/modeler/element-templates/template-example)** - A complete example showing how to create an element template.
