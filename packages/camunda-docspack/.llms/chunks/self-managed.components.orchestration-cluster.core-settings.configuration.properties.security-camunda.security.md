# Property reference — Security — `camunda.security`

| Property                                 | Description                                                                                         | Default value         | Overridable per Physical Tenant |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------- | --------------------- | :------------------------------ |
| `camunda.security.id-validation-pattern` | A Java regular expression that validates the user-defined identifiers of Identity-related entities. | `^[a-zA-Z0-9_@.+-]+$` | Yes                             |
