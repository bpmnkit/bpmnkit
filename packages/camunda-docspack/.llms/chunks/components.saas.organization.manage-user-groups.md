# Manage user groups

Control the level of access a user or group has to perform tasks in the system via user task access restrictions.

Organize users into groups within your organization.


## Creating a group

To create a group in Camunda Hub:

1. In the left navigation, click **Organization > Manage organization**.
1. On the **Groups** tab, select **Create group**.


## Adding users to a group

1. In the left navigation, click **Organization > Manage organization**.
1. On the **Groups** tab, select a group.
1. Click **Assign members**.
