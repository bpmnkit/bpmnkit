# Property reference — Security — `CAMUNDA_SECURITY_INITIALIZATION_DEFAULTROLES`

| Property                                                             | Description                                  | Default value | Overridable per Physical Tenant |
| -------------------------------------------------------------------- | -------------------------------------------- | ------------- | :------------------------------ |
| `CAMUNDA_SECURITY_INITIALIZATION_DEFAULTROLES_<ROLE>_CLIENTS_0`      | Clients assigned to the `<role>` role.       |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_DEFAULTROLES_<ROLE>_GROUPS_0`       | Groups assigned to the `<role>` role.        |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_DEFAULTROLES_<ROLE>_MAPPINGRULES_0` | Mapping rules assigned to the `<role>` role. |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_DEFAULTROLES_<ROLE>_USERS_0`        | Users assigned to the `<role>` role.         |               | Yes                             |
