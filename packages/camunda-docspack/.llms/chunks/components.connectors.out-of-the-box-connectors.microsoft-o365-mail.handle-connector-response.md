# Microsoft 365 connector — Handle connector response

The Microsoft 365 Connector is a protocol connector, meaning it is built on top of the **HTTP REST connector**, therefore
[handling response is still applicable](https://docs.camunda.io/docs/next/components/connectors/protocol/rest#response).
