# Data types

On overview of the available data types in DMN.

Camunda supports the following data types for DMN:

| Type name         | Associated FEEL type                                                                                      |
| ----------------- | --------------------------------------------------------------------------------------------------------- |
| number            | [Number](https://docs.camunda.io/docs/next/components/modeler/feel/language-guide/feel-data-types#number)                               |
| string            | [String](https://docs.camunda.io/docs/next/components/modeler/feel/language-guide/feel-data-types#string)                               |
| boolean           | [Boolean](https://docs.camunda.io/docs/next/components/modeler/feel/language-guide/feel-data-types#boolean)                             |
| time              | [Time](https://docs.camunda.io/docs/next/components/modeler/feel/language-guide/feel-data-types#time)                                   |
| date              | [Date](https://docs.camunda.io/docs/next/components/modeler/feel/language-guide/feel-data-types#date)                                   |
| dateTime          | [Date-Time](https://docs.camunda.io/docs/next/components/modeler/feel/language-guide/feel-data-types#date-time)                         |
| dayTimeDuration   | [Days-Time-Duration](https://docs.camunda.io/docs/next/components/modeler/feel/language-guide/feel-data-types#days-time-duration)       |
| yearMonthDuration | [Years-Months-Duration](https://docs.camunda.io/docs/next/components/modeler/feel/language-guide/feel-data-types#years-months-duration) |
| Any               | Wildcard for any type                                                                                     |

The data types can be used in the type definitions of DMN elements, for example:

- [Decision table input](https://docs.camunda.io/docs/next/components/modeler/dmn/decision-table-input#input-type-definition)
- [Decision table output](https://docs.camunda.io/docs/next/components/modeler/dmn/decision-table-output#output-type-definition)
- [Decision literal expression variable](https://docs.camunda.io/docs/next/components/modeler/dmn/decision-literal-expression#variable-type-definition)
