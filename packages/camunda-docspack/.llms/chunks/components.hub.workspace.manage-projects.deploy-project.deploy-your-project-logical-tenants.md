# Deploy your project — Deploy your project — Logical Tenants

If multi-tenancy is enabled, provide a [Logical Tenant](https://docs.camunda.io/docs/next/self-managed/concepts/multi-tenancy/logical-tenants) for the target environment. If the environment has more than one Logical Tenant, choose the one to deploy to. If it has exactly one, Camunda Hub selects it automatically. On SaaS, a cluster that doesn't support tenants doesn't need one.
