# REST connector — Make your REST connector executable — Configure a proxy server in Self-Managed

In Self-Managed environments, you can configure the connector runtime to route HTTP requests through a proxy server using JVM properties or environment variables. See [HTTP proxy configuration](https://docs.camunda.io/docs/next/self-managed/components/connectors/http-proxy-configuration) for details.
