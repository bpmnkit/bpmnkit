# Build your first AI agent

Get started with Camunda agentic orchestration by running your first AI agent.

Beginner
Time estimate: 45 minutes

Get started with Camunda [agentic orchestration](https://docs.camunda.io/docs/next/components/agentic-orchestration/agentic-orchestration-overview) by building and running your first [AI agent](https://docs.camunda.io/docs/next/reference/glossary#ai-agent).


## About

In this guide, you will build a Camunda [AI agent](https://docs.camunda.io/docs/next/components/agentic-orchestration/ai-agents): the native agent type that orchestrates tools in an [ad-hoc sub-process](https://docs.camunda.io/docs/next/components/modeler/bpmn/ad-hoc-subprocesses/ad-hoc-subprocesses) executed by the Camunda engine.

Specifically, you will:

- Run your AI agent using [Camunda 8 SaaS](https://accounts.cloud.camunda.io/signup) or locally with [Camunda 8 Self-Managed](https://docs.camunda.io/docs/next/self-managed/about-self-managed).
- Use an [AI Agent connector](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/agentic-ai-aiagent) to provide interaction and reasoning capabilities to the AI agent.
- Use an [ad-hoc sub-process](https://docs.camunda.io/docs/next/components/modeler/bpmn/ad-hoc-subprocesses/ad-hoc-subprocesses) to define the tools the AI agent should use.
- Integrate a [Large Language Model (LLM)](https://docs.camunda.io/docs/next/reference/glossary#large-language-model-llm) into your AI agent.

After completing it, you will have an example AI agent running in Camunda 8.
