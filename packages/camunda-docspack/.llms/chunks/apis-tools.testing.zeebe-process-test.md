# Migrate from Zeebe Process Test

**Warning**
Zeebe Process Test was removed in Camunda 8.10. Use [Camunda Process Test](https://docs.camunda.io/docs/next/apis-tools/testing/getting-started) instead.

For the release-level summary of this removal, see the [8.10 release announcement](https://docs.camunda.io/docs/next/reference/announcements-release-notes/8100/8100-announcements#removal-of-legacy-apis-tasklist-v1-dependent-features-and-zeebe-process-test).

Use [Camunda Process Test](https://docs.camunda.io/docs/next/apis-tools/testing/getting-started) for current process testing, and review the [migration guide](https://docs.camunda.io/docs/next/apis-tools/migration-manuals/migrate-to-camunda-process-test) to replace old ZPT dependencies, annotations, and assertions.
