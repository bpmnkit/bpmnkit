# Modeling in Camunda Hub

Camunda Hub provides a collaborative, browser-based interface for modeling BPMN, DMN, Camunda Forms, and element templates for Camunda 8. It enables teams to collaboratively design, implement, and deploy processes.

Camunda Hub provides a collaborative, browser-based interface for modeling BPMN, DMN, Camunda Forms, and element templates for Camunda 8. It enables teams to collaboratively design, implement, and deploy processes.


## Key features

| Feature                                                                       | Description                                                                                     |
| ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| [BPMN, DMN, and Forms modeling](https://docs.camunda.io/docs/next/components/modeler/bpmn/bpmn)                | Create and edit BPMN diagrams, DMN decision tables, and Camunda Forms directly in your browser. |
| [Element templates](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/element-templates/using-templates)                   | Reuse building blocks to standardize modeling across teams and workspaces.                      |
| [Collaboration](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/collaboration/collaboration)                             | Work with team members to speed up the process development cycle.                               |
| [Test mode](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/validation/test-your-process)                                  | Test and validate processes during development.                                                 |
| [Camunda Marketplace](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/modeling/camunda-marketplace)                      | Extend functionality with prebuilt blueprints and connectors.                                   |
| [Projects](https://docs.camunda.io/docs/next/components/hub/workspace/manage-projects/manage-projects)      | Work with sets of files and deploy them in a single bundle.                                     |
| [Git synchronization](https://docs.camunda.io/docs/next/components/hub/workspace/manage-projects/git-sync)  | Connect projects to Git repositories for version control.                                       |
| [Process landscape visualization](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/process-landscape-visualization)       | View dependencies and interactions between processes at a glance.                               |
| [Intelligent Document Processing (IDP)](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/intelligent-document-processing) | Extract and process data from documents to accelerate process automation.                       |
| [AI-powered assistance](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/modeling/advanced-modeling/camunda-docs-ai)        | Get intelligent modeling suggestions and automation support.                                    |
