# Property reference — Security — `orchestration.security.authentication`

| Property                                                              | Description                                                                                                                                                                                                                                                                                                                                            | Default value |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------- |
| `orchestration.security.authentication.method`                        | The authentication method to use. Options: `basic`, `oidc`. The chart value is empty by default and inherits from `global.security.authentication.method`, which is `basic`.                                                                                                                                                                           | `basic`       |
| `orchestration.security.authentication.authenticationRefreshInterval` | **Deprecated in chart 15.x.** The interval at which the memberships (groups, roles, tenants, component authorizations) are refreshed for logged in users. Find more details in [webserver and security](https://docs.camunda.io/docs/next/self-managed/components/orchestration-cluster/core-settings/configuration/webserver#propagation-of-membership-changes-to-active-sessions). | `PT30S`       |
| `orchestration.security.authentication.unprotectedApi`                | **Deprecated in chart 15.x.** If the API can be used without authentication.                                                                                                                                                                                                                                                                           | `false`       |
