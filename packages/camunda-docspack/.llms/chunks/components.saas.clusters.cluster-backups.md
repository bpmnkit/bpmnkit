# Create cluster backups

If your organization works within Camunda's Enterprise plan, you can create cluster backups.

If your organization works within Camunda's [Enterprise](https://camunda.com/pricing/) plan, you can create a manual and scheduled [backups](https://docs.camunda.io/docs/next/components/saas/backups) of your cluster.

**Note**
This page applies to Camunda 8 SaaS. For clusters in Self-Managed, see [clusters in Self-Managed](https://docs.camunda.io/docs/next/components/hub/organization/manage-clusters/index).


## Backup limit

Only the three most recent successful backups of each type are kept, meaning you can have three manual and three scheduled backups. If you already have three backups of a type, the oldest backup is automatically removed.
