# Usage metrics

Learn more about Camunda Hub (Self-Managed) usage metrics.

With Camunda Hub, you can access usage metrics from Operate and Tasklist. The corresponding page allows you to select the time period and the clusters, and displays the subsequent consumption data. The same endpoints are queried as described [in the usage metrics documentation](https://docs.camunda.io/docs/next/self-managed/components/orchestration-cluster/core-settings/concepts/usage-metrics).

**Note**
To retrieve usage metrics, you must be running Tasklist or Operate.
