# Camunda 8 SaaS — Sign up — Zeebe

The [Zeebe](https://docs.camunda.io/docs/next/components/zeebe/zeebe-overview) core process automation engine that powers Camunda 8 is fully managed by Camunda in SaaS, and is already pre-integrated with other Camunda 8 components such as Operate, Optimize, and Tasklist.

You can interact with Zeebe in SaaS using both gRPC and REST APIs. See [working with APIs and tools](https://docs.camunda.io/docs/next/apis-tools/working-with-apis-tools).
