# Property reference — Cluster — `camunda.cluster.partitioning`

| Property                                                             | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Default value | Overridable per Physical Tenant |
| :------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------ | :------------------------------ |
| `camunda.cluster.partitioning.scheme`                                | Configures how partitions are distributed across brokers (the partitioning scheme). Available options are ROUND_ROBIN, FIXED, and ZONE_AWARE.When using FIXED, the broker-to-partition mapping must be specified under camunda.cluster.partitioning.fixed.When using ZONE_AWARE, the zones must be specified under camunda.cluster.partitioning.zone-aware.zones. | `ROUND_ROBIN` | No                              |
| `camunda.cluster.partitioning.fixed[].partition-id`                  | Partition ID entry used when camunda.cluster.partitioning.scheme is set to FIXED.                                                                                                                                                                                                                                                                                                                                                                | `1`           | No                              |
| `camunda.cluster.partitioning.fixed[].nodes[].nodes-id`              | Broker node ID for a fixed partition mapping entry (used when camunda.cluster.partitioning.scheme is FIXED).                                                                                                                                                                                                                                                                                                                                     | `0`           | No                              |
| `camunda.cluster.partitioning.fixed[].nodes[].priority`              | Priority value associated with a broker node in the fixed partitioning configuration.                                                                                                                                                                                                                                                                                                                                                                                      | `1`           | No                              |
| `camunda.cluster.partitioning.zone-aware.zones[].name`               | The name of the zone. Used when camunda.cluster.partitioning.scheme is set to ZONE_AWARE. Follows the same rules as camunda.cluster.zone.                                                                                                                                                                                                                                                                                           | -             | No                              |
| `camunda.cluster.partitioning.zone-aware.zones[].number-of-brokers`  | The total number of brokers deployed in this zone. The sum of all brokers across all zones should be equal to `camunda.cluster.size`                                                                                                                                                                                                                                                                                                                                       | -             | No                              |
| `camunda.cluster.partitioning.zone-aware.zones[].number-of-replicas` | The number of replicas for each replication group in this zone. The sum of all replicas across all zones should be equal to `camunda.cluster.replication-factor`                                                                                                                                                                                                                                                                                                           | -             | No                              |
| `camunda.cluster.partitioning.zone-aware.zones[].priority`           | The priority of the zone. Higher priorities translate to higher Raft election priorities, skewing partition leaders toward the highest-priority zone.                                                                                                                                                                                                                                                                                                                      | -             | No                              |
