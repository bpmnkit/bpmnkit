# Users

Learn how to manage user access to an orchestration cluster.

Users are individuals who are granted with access to an orchestration cluster and it's components like Operate, Tasklist and REST API. User management differs depending on whether you are using Camunda 8 SaaS or a Self-Managed installation.


## SaaS

In a SaaS environment, user management is handled through [Camunda Hub](https://docs.camunda.io/docs/next/components/hub/organization/manage-users/index). From Camunda Hub, you can [invite new users to your organization](https://docs.camunda.io/docs/next/components/hub/organization/manage-users/create-manage-users#add-a-user) and [manage their roles](https://docs.camunda.io/docs/next/components/hub/organization/manage-users/create-manage-users#edit-or-remove-a-user). For more advanced user management, you can configure [single sign-on (SSO)](https://docs.camunda.io/docs/next/components/hub/organization/manage-organization-settings/external-sso) to integrate with your own identity provider.
