# Camunda app integrations

Bring Camunda process management into Microsoft Teams and Slack with one shared backend.

App integrations bring Camunda tasks, processes, and notifications into the chat tool your team already uses, currently Microsoft Teams and Slack. You can use one platform, the other, or both.

**Important**
App integrations are released as an [early access](https://docs.camunda.io/docs/next/components/early-access/overview) alpha feature to allow you to test and participate in development by sharing feedback before general availability, and are subject to alpha feature limitations.


## About

One backend, the App Integrations service, serves both platforms: one installation, one database, one notification-rule model, and one CLI. Each platform's app is registered separately, so an organization using only one platform registers only that one.

| Platform                                | Description                                                                                 |
| :-------------------------------------- | :------------------------------------------------------------------------------------------ |
| [Microsoft Teams](https://docs.camunda.io/docs/next/components/camunda-integrations/app-integrations/microsoft-teams) | A chatbot and visual tabs for browsing tasks, starting processes, and monitoring incidents. |
| [Slack](https://docs.camunda.io/docs/next/components/camunda-integrations/app-integrations/slack)                     | A slash command and direct message for browsing tasks and starting processes.               |
