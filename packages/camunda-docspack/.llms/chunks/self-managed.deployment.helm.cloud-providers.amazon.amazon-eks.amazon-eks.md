# Amazon EKS

Deploy Camunda 8 Self-Managed on Amazon EKS

Amazon Elastic Kubernetes Service ([Amazon EKS](https://aws.amazon.com/eks/)) is a managed
container service to run and scale Kubernetes applications in the cloud or on-premises.

Camunda 8 Self-Managed can be deployed on any Kubernetes cluster using [Helm charts](https://docs.camunda.io/docs/next/self-managed/deployment/helm/install/quick-install). Deployment requirements, including cloud provider-specific information, is available on our [Kubernetes deployment reference](https://docs.camunda.io/docs/next/self-managed/reference-architecture/kubernetes).
