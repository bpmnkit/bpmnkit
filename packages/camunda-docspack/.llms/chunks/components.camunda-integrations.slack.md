# Slack

Camunda for Slack is part of Camunda app integrations. Find setup, features, and troubleshooting there.

Camunda for Slack is part of [Camunda app integrations](https://docs.camunda.io/docs/next/components/camunda-integrations/app-integrations/app-integrations), which connect Camunda to the chat tool your team uses. You can run it without Microsoft Teams.

**Important**
App integrations are released as an [early access](https://docs.camunda.io/docs/next/components/early-access/overview) alpha feature to allow you to test and participate in development by sharing feedback before general availability, and are subject to alpha feature limitations.

Find the documentation you're looking for:

- [Camunda for Slack](https://docs.camunda.io/docs/next/components/camunda-integrations/app-integrations/slack), the `/camunda` slash command and direct message.
- [Notification rules](https://docs.camunda.io/docs/next/components/camunda-integrations/app-integrations/notification-rules).
- [Install](https://docs.camunda.io/docs/next/components/camunda-integrations/app-integrations/installation).
- [Troubleshoot](https://docs.camunda.io/docs/next/components/camunda-integrations/app-integrations/troubleshoot).

This page is not the [Slack connector](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/slack), which is a separate product that uses your own app registration and credentials in the process model. If your organization uses app integrations, the [App Integrations connector](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/app-integrations) sends through the app your users already have connected.
