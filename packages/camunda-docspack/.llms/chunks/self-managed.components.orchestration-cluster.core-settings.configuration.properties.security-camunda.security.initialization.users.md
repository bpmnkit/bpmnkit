# Property reference — Security — `camunda.security.initialization.users`

| Property                                             | Description                          | Default value | Overridable per Physical Tenant |
| ---------------------------------------------------- | ------------------------------------ | ------------- | :------------------------------ |
| `camunda.security.initialization.users.[0].email`    | The email address of the first user. |               | Yes                             |
| `camunda.security.initialization.users.[0].name`     | The name of the first user.          |               | Yes                             |
| `camunda.security.initialization.users.[0].password` | The password of the first user.      |               | Yes                             |
| `camunda.security.initialization.users.[0].username` | The username of the first user.      |               | Yes                             |
