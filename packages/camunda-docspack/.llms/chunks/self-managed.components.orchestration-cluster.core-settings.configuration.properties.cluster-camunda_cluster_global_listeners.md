# Property reference — Cluster — `CAMUNDA_CLUSTER_GLOBAL_LISTENERS`

| Property                                                        | Description                                                                                                                                                                                                                                                                                                                  | Default value | Overridable per Physical Tenant |
| :-------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------ | :------------------------------ |
| `CAMUNDA_CLUSTER_GLOBAL_LISTENERS_USER_TASK`                    | List of configuration entries for global user task listeners (see also [Global user task listeners](https://docs.camunda.io/docs/next/components/concepts/global-user-task-listeners).)                                                                                                                                                             | No entries    | Yes                             |
| `CAMUNDA_CLUSTER_GLOBAL_LISTENERS_USER_TASK_0_ID`               | User-provided unique identifier for the listener. This identifier is used to interact with the global listener through API.                                                                                                                                                                                           | -             | Yes                             |
| `CAMUNDA_CLUSTER_GLOBAL_LISTENERS_USER_TASK_0_EVENT_TYPES`      | List of user task event types that trigger the listener. Supported values are creating, assigning, updating, completing, and canceling. The shorthand all value is also available if the listener should react to all lifecycle events. | -             | Yes                             |
| `CAMUNDA_CLUSTER_GLOBAL_LISTENERS_USER_TASK_0_TYPE`             | The name of the job type. Used as a reference to specify which job workers request the respective task listener job. For example, order-items.                                                                                                                                                           | -             | Yes                             |
| `CAMUNDA_CLUSTER_GLOBAL_LISTENERS_USER_TASK_0_RETRIES`          | The number of retries for the user task listener job.                                                                                                                                                                                                                                                                 | `3`           | Yes                             |
| `CAMUNDA_CLUSTER_GLOBAL_LISTENERS_USER_TASK_0_AFTER_NON_GLOBAL` | Boolean flag indicating whether the listener should run after model-level listeners.                                                                                                                                                                                                                                  | `false`       | Yes                             |
| `CAMUNDA_CLUSTER_GLOBAL_LISTENERS_USER_TASK_0_PRIORITY`         | The priority of the listener. Higher priority listeners are executed before lower priority ones. It must be an integer between 0 and 100.                                                                                                                                                                             | `50`          | Yes                             |
