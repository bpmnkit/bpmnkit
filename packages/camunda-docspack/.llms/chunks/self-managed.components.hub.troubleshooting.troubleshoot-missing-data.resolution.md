# Troubleshoot missing data — Resolution

To restore workspace access for the affected users, users with the **Hub Admin** role already have the [access](https://docs.camunda.io/docs/next/components/hub/organization/users-and-roles.md?edition=self-managed#elevated-workspace-access-self-managed) needed to reassign members to projects that have no members.
