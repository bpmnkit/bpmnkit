# Use connectors — Disable automatic connector template fetching

Disable automatic fetching of connector templates using the `#disable-connector-templates` [feature flag](https://docs.camunda.io/docs/next/components/modeler/desktop-modeler/flags/flags#disable-connector-templates).


## Add connector templates manually

For full control over the building blocks offered by Desktop Modeler, download element templates for individual Camunda 8 connectors manually (for example, through the [Camunda Marketplace](https://marketplace.camunda.com/)). Make them available to Desktop Modeler via the element template [search paths](https://docs.camunda.io/docs/next/components/modeler/desktop-modeler/element-templates/configuring-templates).
