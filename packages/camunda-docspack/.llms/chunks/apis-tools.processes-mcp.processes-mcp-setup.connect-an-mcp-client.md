# Enable and connect — Connect an MCP client

Once the Processes MCP Server is enabled, you can connect any MCP-compliant client. The approach depends on your client's capabilities and authentication requirements.

**Important**
When you [create API client credentials](https://docs.camunda.io/docs/next/components/saas/clusters/manage-api-clients#create-a-client) in Camunda Hub, all required connection details, including the base URL, OAuth endpoint, client ID, and audience, are displayed on the credentials page.
