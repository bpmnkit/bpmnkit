# Display and download a document — Download a document using the Orchestration Cluster REST API

You can also download a document from your Camunda 8 cluster using the Orchestration Cluster REST API.

**Note**
This is currently supported for document stores of type: [AWS, GCP, in-memory (non-production), local (non-production)](https://docs.camunda.io/docs/next/self-managed/concepts/document-handling/configuration/index).

Learn more about this request in the [Orchestration Cluster REST API docs](https://docs.camunda.io/docs/next/apis-tools/orchestration-cluster-api-rest/specifications/get-document.api).
