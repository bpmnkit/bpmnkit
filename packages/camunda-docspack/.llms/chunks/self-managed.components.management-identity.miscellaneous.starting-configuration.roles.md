# Starting configuration for Identity — Roles

Both `Web Modeler`/`Web Modeler Admin` and the equivalent `Hub`/`Hub Admin` roles are provisioned and grant identical permissions. See [Management Identity roles and permissions](https://docs.camunda.io/docs/next/self-managed/upgrade/components/890-to-8100#management-identity-roles-and-permissions) in the 8.9 to 8.10 upgrade guide for details.

| Name                   | Created/updated with component |
| :--------------------- | :----------------------------- |
| Identity               | All                            |
| Operate                | Operate                        |
| Optimize               | Optimize                       |
| Tasklist               | Tasklist                       |
| Web Modeler            | Hub                            |
| Web Modeler Admin      | Hub                            |
| Hub                    | Hub                            |
| Hub Admin              | Hub                            |
| Console                | Hub                            |
| DevOps                 | Hub                            |
| Analyst                | Hub, Optimize                  |
| Hub API - Cluster Ping | Hub                            |
