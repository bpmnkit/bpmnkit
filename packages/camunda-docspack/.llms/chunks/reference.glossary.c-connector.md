# Glossary — C — Connector

[Connectors](https://docs.camunda.io/docs/next/components/connectors/introduction) are reusable building blocks you can use to easily connect [processes](#process) to external systems, applications, and data.

Connector types:

- [Outbound](#outbound-connector)
- [Inbound](#inbound-connector)
- [Protocol](#protocol-connector)
