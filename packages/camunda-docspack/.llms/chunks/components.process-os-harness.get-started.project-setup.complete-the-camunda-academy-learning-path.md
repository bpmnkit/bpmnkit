# Set up your organization for ProcessOS Harness — Complete the Camunda Academy learning path

Complete the ProcessOS Harness learning path in [Camunda Academy](https://academy.camunda.com/) before you start a project.

Academy is where you build the capability to work with ProcessOS Harness, including the mindset shift that working with non-deterministic AI output requires. This documentation is written for a builder who has already done that, and it's here to keep you unblocked rather than to teach the approach from scratch.

Treat the learning path as a prerequisite for your first project.


## Plan the effort

ProcessOS Harness runs many agent iterations, so a journey has a real token cost. Plan for roughly $300 to $600 in tokens and six to eight hours for one journey from discovery through implementation. Treat this as a planning input rather than a fixed price. Run configuration and process complexity heavily impact token usage.

Involve your SMEs early. ProcessOS Harness changes their role from main contributor to reviewer, which reduces their total effort, but they still need to be available at the review gates in each phase. A project stalls when a review cycle has no reviewer.
