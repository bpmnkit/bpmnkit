# Run or publish your process — Publishing a process — Incorrect authorizations

When using Camunda Hub to deploy a process model or start a process instance, you may encounter issues related to [resource authorizations](https://docs.camunda.io/docs/next/components/concepts/access-control/authorizations). Verify the credentials you're using have the required authorizations to deploy a process model or start a process instance on the selected cluster and tenant. Note that deployments and process starts are performed **as your logged-in user**, so the necessary authorizations must be assigned to your user account.
