# Get started with human task orchestration — Step 2: Design a form

You have now designed the process. To allow the user to make the decision, you will now design a [form](https://docs.camunda.io/docs/next/components/modeler/forms/camunda-forms-reference). Forms can be added to user tasks and start events to capture user input, and the user input can be used to route the process flow, to make calls to APIs, or to orchestrate your services.
