# Mapping rules

Learn how to create mapping rules for flexible resource access in the Orchestration Cluster for OIDC setups.

Mapping rules provide flexible access to Orchestration Cluster resources based on claims in a user's or client's OIDC access token.

In Self-Managed, the Mapping Rules UI is always available. In SaaS, it becomes available once you [connect an external identity provider](https://docs.camunda.io/docs/next/components/saas/clusters/connect-external-identity-provider) to the cluster. The mapping rules API works regardless, but without an external identity provider there are no custom claims to map against.

**Info**
To learn more, see [mapping rules](https://docs.camunda.io/docs/next/components/concepts/access-control/mapping-rules).
