# Property reference — Security — `CAMUNDA_SECURITY_INITIALIZATION_GROUPS`

| Property                                                 | Description                               | Default value | Overridable per Physical Tenant |
| -------------------------------------------------------- | ----------------------------------------- | ------------- | :------------------------------ |
| `CAMUNDA_SECURITY_INITIALIZATION_GROUPS_0_GROUP_ID`      | The ID of this group.                     |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_GROUPS_0_NAME`          | The name of this group.                   |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_GROUPS_0_DESCRIPTION`   | The description of this group.            |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_GROUPS_0_CLIENTS`       | The clients assigned to this group.       |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_GROUPS_0_MAPPING_RULES` | The mapping rules assigned to this group. |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_GROUPS_0_USERS`         | The users assigned to this group.         |               | Yes                             |
