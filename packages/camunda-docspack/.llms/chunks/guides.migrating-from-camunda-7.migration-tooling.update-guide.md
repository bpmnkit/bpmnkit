# Update guide

Learn about breaking changes and migration steps to consider when updating Migration Tooling between versions.

In this guide, you'll learn about the breaking changes and migration steps to consider when you upgrade Migration Tooling.

**Note**
Migration Tooling follows [semantic versioning](https://semver.org/).


## Prerequisites

Before you update:

1. Check the [version compatibility matrix](https://docs.camunda.io/docs/next/guides/migrating-from-camunda-7/migration-tooling/version-compatibility) to confirm your Migration Tooling version is compatible with your Camunda 7 and Camunda 8 versions.
2. Apply database schema updates for the new version, if required. Check the release notes for details.
3. Review the [Migration Tooling release notes](https://github.com/camunda/camunda-7-to-8-migration-tooling/releases) for your target version.
