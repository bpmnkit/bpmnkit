# Deploy a diagram

Follow these steps to directly deploy diagrams and start process instances in Camunda 8.

Desktop Modeler can directly deploy diagrams and start process instances in Camunda 8. Follow the steps below to deploy a diagram to Camunda.

1. Set up and select a connection by following [Connect to Camunda 8](https://docs.camunda.io/docs/next/components/modeler/desktop-modeler/connect-to-camunda-8) guide.

   ![Connection selector showing the Dev connection selected](./img/connection-selector-dev-connection.png)

2. Click the **Deploy** icon:

   ![deploy icon](./img/deploy-icon.png)

3. Click **Deploy** to perform the actual deployment.

   ![deploy diagram](./img/deploy-diagram.png)

4. If the deployment is successful, you will see a confirmation message:

   ![deployment successful](./img/deploy-diagram-success.png)

**Note**
As a next step, [start a new process instance](https://docs.camunda.io/docs/next/components/modeler/desktop-modeler/start-instance).
