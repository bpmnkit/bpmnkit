# Manage user groups — User task access restrictions

**Info**
User task access restrictions were removed in Camunda 8.10 together with Tasklist V1. Use [user task authorization](https://docs.camunda.io/docs/next/components/tasklist/user-task-authorization) and [authorization-based access control](https://docs.camunda.io/docs/next/components/concepts/access-control/authorizations) for current task visibility rules.
