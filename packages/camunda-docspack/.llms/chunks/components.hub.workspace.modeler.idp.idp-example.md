# Example IDP integration

A worked example showing how you can integrate a published IDP document extraction template into a simple process in Camunda Hub.

This worked example shows how you can [integrate IDP](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/idp/idp-configuration) into a simple process.


## About this worked example

This worked example demonstrates how a published [document extraction template](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/idp/idp-document-extraction) can be used to extract data from a document uploaded via [Tasklist](https://docs.camunda.io/docs/next/components/tasklist/introduction-to-tasklist).

In this example, a process is set up with the following steps:

1. **Upload document**: A PDF document is uploaded manually in Tasklist.
1. **Extract data**: A published document extraction template automatically extracts the required data from the PDF document.
1. **View results**: The extraction results are viewed.
