# Property reference — Data - secondary storage — `camunda.data.secondary-storage`

| Property                                                        | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | Default value                            | Overridable per Physical Tenant |
| :-------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------- | :------------------------------ |
| `camunda.data.secondary-storage.type`                           | Type of secondary storage to use.Example: `elasticsearch`, `opensearch`, `rdbms`, or `none`.                                                                                                                                                                                                                                                                                                                                                                                    | `elasticsearch` (orchestration default). | Yes                             |
| `camunda.data.secondary-storage.autoconfigure-camunda-exporter` | If enabled, the default exporter `camundaexporter` is automatically configured using the secondary-storage properties.Manual configuration of `camundaexporter` is not required.If disabled, `camundaexporter` will not be configured automatically, but can still be enabled through manual configuration if required.Manual configuration of `camundaexporter` is generally not recommended, and can result in unexpected behavior if not configured correctly. | `true`                                   | Yes                             |
| `camunda.data.secondary-storage.retention.enabled`              | If true, the ILM Policy is created and applied to the index templates.                                                                                                                                                                                                                                                                                                                                                                                                                        | `true`                                   | Yes                             |
| `camunda.data.secondary-storage.retention.minimum-age`          | Defines how old the data must be before the data is deleted, set as a duration.                                                                                                                                                                                                                                                                                                                                                                                                               | `30d`                                    | Yes                             |
