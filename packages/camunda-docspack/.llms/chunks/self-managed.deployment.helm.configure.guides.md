# Helm chart user guides

Various use cases configuring and deploying Camunda 8.

Camunda 8 Self-Managed is highly customizable and can be deployed in different setups. This section highlights various use cases and scenarios of configuring Camunda 8 beyond the default values.

Each guide is considered complete and a standalone use case. However, view the [deploying Camunda 8 using Helm charts](https://docs.camunda.io/docs/next/self-managed/deployment/helm/install/quick-install) page, as this is the base for all guides.
