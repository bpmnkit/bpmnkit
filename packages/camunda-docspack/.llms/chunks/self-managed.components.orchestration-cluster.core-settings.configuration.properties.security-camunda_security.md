# Property reference — Security — `CAMUNDA_SECURITY`

| Property                               | Description                                                                                         | Default value         | Overridable per Physical Tenant |
| -------------------------------------- | --------------------------------------------------------------------------------------------------- | --------------------- | :------------------------------ |
| `CAMUNDA_SECURITY_IDVALIDATIONPATTERN` | A Java regular expression that validates the user-defined identifiers of Identity-related entities. | `^[a-zA-Z0-9_@.+-]+$` | Yes                             |
