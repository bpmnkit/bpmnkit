# Property reference — Security — `CAMUNDA_SECURITY_INITIALIZATION_TENANTS`

| Property                                                  | Description                                | Default value | Overridable per Physical Tenant |
| --------------------------------------------------------- | ------------------------------------------ | ------------- | :------------------------------ |
| `CAMUNDA_SECURITY_INITIALIZATION_TENANTS_0_TENANT_ID`     | The ID of this tenant.                     |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_TENANTS_0_NAME`          | The name of this tenant.                   |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_TENANTS_0_DESCRIPTION`   | The description of this tenant.            |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_TENANTS_0_CLIENTS`       | The clients assigned to this tenant.       |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_TENANTS_0_GROUPS`        | The groups assigned to this tenant.        |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_TENANTS_0_MAPPING_RULES` | The mapping rules assigned to this tenant. |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_TENANTS_0_ROLES`         | The roles assigned to this tenant.         |               | Yes                             |
| `CAMUNDA_SECURITY_INITIALIZATION_TENANTS_0_USERS`         | The users assigned to this tenant.         |               | Yes                             |
