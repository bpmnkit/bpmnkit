# Process modeling — Open the modeler in Camunda Hub

1. Log in to Camunda 8 SaaS.
2. Navigate to a workspace.
3. In your workspace, open a project and select a file to edit.


## Get Desktop Modeler

If you want to model locally, work offline, or edit the underlying XML directly, download Desktop Modeler for macOS, Windows, or Linux from the [Camunda downloads page](https://camunda.com/download/modeler/).

For installation details and features, see [Desktop Modeler](https://docs.camunda.io/docs/next/components/modeler/desktop-modeler/index).

**Note**
Desktop Modeler includes an XML editor for [BPMN](https://docs.camunda.io/docs/next/components/modeler/bpmn/bpmn) and [Decision Model and Notation (DMN)](https://docs.camunda.io/docs/next/components/modeler/dmn/dmn) diagrams, with its own undo and redo history, search and replace, and XML syntax highlighting.

If you use both tools, see [using Camunda Hub and Desktop Modeler together](https://docs.camunda.io/docs/next/components/modeler/using-hub-and-desktop-modeler-together).
