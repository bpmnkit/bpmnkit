# Camunda data purge — Purge data

You will need access to the Cluster API as described in the [Cluster scaling guide](https://docs.camunda.io/docs/next/self-managed/operational-guides/self-managed/components/orchestration-cluster/zeebe/operations/cluster-scaling) to perform the purge.

**Danger**
The purge operation is irreversible. It will delete the runtime data in the cluster and the historical data in the exporters! Make sure to back up your data before proceeding.
