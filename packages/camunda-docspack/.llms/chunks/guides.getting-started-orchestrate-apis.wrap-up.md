# Get started with API orchestration — Wrap up

Congratulations! You successfully built your first API orchestration solution with Camunda 8.

Camunda 8 empowers users to automate processes faster. With connectors, you can access APIs without writing code.

Connector tasks are also how you give an [AI agent](https://docs.camunda.io/docs/next/reference/glossary#ai-agent) something to do. An agent can call the same connectors you used here as its tools, and the process still defines which tools the agent is allowed to use.
