# Configure IDP — General requirements

The following prerequisites apply regardless of your cloud provider:

| Prerequisite                                              | Description                                                                                                                                                                                                                                                                                                            |
| :-------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Camunda Hub](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/index) | Camunda Hub is required to create, manage, publish, and integrate [IDP projects](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/idp/idp-projects), [document extraction](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/idp/idp-document-extraction) templates, and [document classification](https://docs.camunda.io/docs/next/components/hub/workspace/modeler/idp/idp-document-classification) templates.IDP does not support Desktop Modeler. |
