# Enable and connect — Connect an MCP client — Use with the MCP Client connectors

You can also connect to the Processes MCP Server from within a BPMN process using Camunda's [MCP Client connectors](https://docs.camunda.io/docs/next/components/connectors/out-of-the-box-connectors/agentic-ai-mcp-client). This allows an AI agent running in an agentic orchestration workflow to invoke your deployed processes as MCP tools.
