# Job dashboard

Use the job dashboard in Camunda Hub to see active job types, track created, completed and failed jobs, spot trends over time, and drill into job worker errors.

Use the job dashboard to see which job types are active, how many jobs are created, completed, and failed, and which job workers are involved. Jobs are available for both environments and clusters, so you can open the job dashboard from an [environment](https://docs.camunda.io/docs/next/components/concepts/environments) or from the [cluster](https://docs.camunda.io/docs/next/components/concepts/clusters) that hosts it. For a cluster, the job dashboard is an aggregated view across all of its environments, which is relevant in Self-Managed, where a cluster can host more than one environment. In SaaS, each cluster hosts one environment.
