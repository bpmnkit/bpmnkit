# Configuration — Multi-tenancy — Troubleshooting

To ensure seamless integration and functionality, the multi-tenancy feature must also be enabled across all associated components [if not configured in Helm](https://docs.camunda.io/docs/next/self-managed/deployment/helm/configure/configure-logical-tenants) so users can view any data from tenants for which they have authorizations configured in Admin.

Find more information (including links to component-specific configuration pages) on the [multi-tenancy concepts page](https://docs.camunda.io/docs/next/components/concepts/multi-tenancy).
