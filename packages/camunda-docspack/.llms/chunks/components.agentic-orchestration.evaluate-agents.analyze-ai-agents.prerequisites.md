# Analyze your AI agents with Optimize — Prerequisites

- You have access to [Optimize](https://docs.camunda.io/docs/next/components/optimize/what-is-optimize).
- You have deployed and run the [AI Agent Chat Quick Start](https://marketplace.camunda.com/en-US/apps/587865) model blueprint. This is needed for Optimize to fetch execution data to analyze. Consider running it using different prompts to trigger various AI agent tools.

**Important**
This guide is a follow-up to [build your first AI agent](https://docs.camunda.io/docs/next/guides/getting-started-agentic-orchestration), in which you use the same example AI agent process. We recommend completing that guide first. However, you can also apply this guide to other AI agent process implementations.
