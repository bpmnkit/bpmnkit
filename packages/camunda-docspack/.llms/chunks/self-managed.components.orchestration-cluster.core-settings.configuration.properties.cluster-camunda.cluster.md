# Property reference — Cluster — `camunda.cluster`

| Property                                | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | Default value   | Overridable per Physical Tenant |
| :-------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------- | :------------------------------ |
| `camunda.cluster.name`                  | Set the name of the cluster.                                                                                                                                                                                                                                                                                                                                                                                                                                                           | `zeebe-cluster` | No                              |
| `camunda.cluster.id`                    | Set the cluster ID used to identify the cluster. It should be unique across clusters.If not configured, the cluster ID will be set to a new random UUID.                                                                                                                                                                                                                                                                                                                        |                 | No                              |
| `camunda.cluster.network.host`          | The network host for internal cluster communication.                                                                                                                                                                                                                                                                                                                                                                                                                                   | `null`          | No                              |
| `camunda.cluster.node-id`               | Specifies the unique id of this broker node in a cluster. The id should be between 0 and number of nodes in the cluster (exclusive).                                                                                                                                                                                                                                                                                                                                                   | `0`             | No                              |
| `camunda.cluster.partition-count`       | The number of partitions in the cluster.                                                                                                                                                                                                                                                                                                                                                                                                                                               | `1`             | Yes                             |
| `camunda.cluster.replication-factor`    | The number of replicas for each partition in the cluster. The replication factor cannot be greater than the number of nodes in the cluster.                                                                                                                                                                                                                                                                                                                                            | `1`             | No                              |
| `camunda.cluster.size`                  | The number of nodes in the cluster.                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `1`             | No                              |
| `camunda.cluster.compression-algorithm` | Configure the compression algorithm for all messages sent between brokers, and between broker and gateway.Available options are NONE, GZIP, and SNAPPY.This can be useful when network latency is high (for example, across data centers), but may impact performance when latency is low.                                                                                                                                        | `NONE`          | No                              |
| `camunda.cluster.gateway-id`            | Set the member ID of this gateway node in the cluster. Only relevant for standalone gateway deployments.                                                                                                                                                                                                                                                                                                                                                                               | `gateway`       | No                              |
| `camunda.cluster.zone`                  | The zone (region or availability zone) this broker belongs to. Used for multi-region deployments. When set, the partitioning scheme (see camunda.cluster.partitioning.scheme) must be set to ZONE_AWARE. If not set, the broker is considered to be in a single-zone setup.Must be at most 63 characters, start with an alphanumeric character (no leading hyphen), and contain only alphanumeric characters and hyphens ([A-Za-z0-9-]). |                 | No                              |
